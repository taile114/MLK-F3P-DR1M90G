# 完整寿命模型的 NPU 加速规划

本文规定从已验证的 CPU 完整推理与 UINT8 硬核卷积出发，评估原 FKP-DVGT 模型加速的步骤和验收条件。已完成训练集校准、124 个分支隔离验证、六个真实权重层及完整模型分段运行时的 184 窗混合回放，CMA 首窗后稳定；应用精度和正式性能尚未验收，全程未重新训练。

## 已有依据

| 项目 | 结论与边界 |
|---|---|
| 完整模型 | 混合 CPU 回放 165 窗，最大参考差约 `8.58e-06`，诊断平均约 199.45 毫秒/窗；[板端 CSV 复核](../results/board/f3p-cpu-mixed-recovered-v1-verification.json)通过 |
| 硬件入口 | 配套 SD 镜像的三个设备和 Alnpu 后端可用，eMMC CPU 基线保留 |
| NPU 数值 | 单个 UINT8 3×3 卷积通过硬核分配、执行事件、1536 个输出及 IRQ 增量复核，见 [实机文件](../results/board/f3p-npu-smoke-recovered-v1-verification.json) |
| 类型限制 | 测试的 u8_s8、s8 卷积配置在当前运行库优化阶段被拒绝，不能直接采用常见的有符号权重量化配置 |
| 首窗热点 | FC 124 次，占非 Constant 工作负载累计 wall-clock 的 18.53%；Ceil 16.98%、Reshape 15.28%，另有大量算术和切片 |

首窗 profile 包含首次执行准备和测量开销，其比例不是稳态端到端占比。小卷积的观测耗时比约 6.91 仅适用于该对照，不能用于推算完整模型收益。运行库接受某个算子，也不保证接受模型的全部尺寸。

融合后的完整 CPU 回放中，样条基函数约占 48%，FC 约占 42%。额外前馈 FC 与输入投影的卷积表达已完成真实层及三轮完整验证；五分支候选耗时约减少 6%，同时相对 FP32 的最大预测偏差增大到约 0.575。当前筛选及验收边界见[额外分支验证](additional-offload-validation.md)，不能继续用上述原生首窗比例估计融合版本收益。

## 第一步：实际尺寸映射对照

[静态 FC 清单](../results/build/rul-linear-shape-inventory.json)包含 24 种 `(B,I,O)`，其中 B 为输入矩阵行数、I/O 为输入/输出维数。代表性边界如下，完整清单为测试覆盖依据：

| 位置 | B | I | O |
|---|---:|---:|---:|
| 输入变换基函数分支 | 110 | 23 | 23 |
| 输入变换样条分支 | 110 | 207 | 23 |
| 通道汇聚样条分支 | 10 | 207 | 1 |
| 时间注意力样条分支 | 11 | 108 | 21 |
| 时间 FF 输出样条分支 | 11 | 1260 | 12 |
| 空间 FF 输出样条分支 | 12 | 1260 | 11 |
| 回归头样条分支 | 1 | 1188 | 64 |
| 最终输出样条分支 | 1 | 576 | 1 |

对照分为原生 FullyConnected 和等价 1×1 Conv 两种表达。矩阵乘法 `X[B,I] × W[O,I]^T` 可表达为 NCHW 输入 `[1,I,1,B]`、权重 `[O,I,1,1]` 的卷积，并恢复输出排列。此处只说明数学映射；Alnpu 是否接受 1×1 核、对应通道数和空间尺寸仍需实测。

若原尺寸不支持，再独立测试通道补齐；补齐到 8 等数值仅作为候选，当前没有证据表明这是硬件必需条件。新增输入通道编码为量化实数零，新增权重贡献也必须为零，不能用字节值 0 代替任意非零 zero-point 表示的实数零。

测试先使用可独立核对的整数输入和权重，逐个尺寸先 CpuRef，再仅请求 Alnpu。记录优化、加载、计算阶段、图中实际后端、profile、中断、误差、饱和及内存占用；不允许静默 CPU 回退。通过的表达再测数据排列和量化/反量化成本，不能只比较 NPU 内核事件时间。

[独立尺寸对照包](npu-linear-validation.md)已完成 74 项 CPU 对照、126768 个输出核对；六种代表性原生 FC 实机通过，B=110 的两种尺寸也通过 1×1 卷积映射。完整矩阵在 m06（B=11、I=12、O=21）的 Alnpu 实际执行阶段发生硬核中断超时，当前停止原始矩阵。

[补齐 FC 对照](npu-fc-padding-validation.md)将物理 I/O 补到 8 的倍数，新增部分为实数零并裁回原始输出。25 项 CPU 对照、44544 个量化输出通过，裁剪结果与未补齐 CpuRef 逐字节一致。冷启动控制组、m06、四种输出 21 通道及全部 24 种补齐尺寸均通过实机，未再出现该超时，最大整数差 1 LSB。该结果限于合成 UINT8 值，真实权重和完整模型精度仍待验证。测试结果保存在 SD 第二分区及仓库回收目录，传输 U 盘不执行文件系统修复。

## 第二步：减少 KAN 的小算子与边界

根据板端首窗 profile，分别评估两个方向：

1. 在 CPU 中合并样条门控和递推计算，减少独立 Ceil、切片、算术和 Reshape 调用。保持原网格、边界定义、样条阶数和已训练权重，先用 FP32 与当前实现逐段、逐窗比较。
2. 对 NPU 支持的尺寸，评估将同一 KAN 的基函数分支和样条分支拼接为一次线性计算，或在形状允许时合并 Q/K/V 投影。拼接次序、权重排列和量化尺度需独立核对；合并后输入通道增加，仍须通过硬件尺寸验证。

CPU 工作区复用和样条/PCC/LayerNorm 融合已通过验证，见[融合对照](operator-fusion-validation.md)。KAN 分支拼接与 Q/K/V 合并仍为待验证方案。保持五处 GELU 等边界明确，计入中间张量复制及同步成本；先优化实测热点，再比较独立 CPU 优化、NPU 分段和组合方案。

## 第三步：训练集量化校准

仅在映射和数值对照通过后，使用现有训练集 543 个窗口收集候选层激活范围，禁止用验证集 184 窗或测试集 165 窗计算校准参数。归一化沿用冻结的训练集参数，不重新拟合测试数据。

优先评估已通过小卷积测试的 QAsymmU8 激活、权重与输出，包含独立的尺度、zero-point 和相应 Signed32 偏置。模型权重含负值，UINT8 表示应通过 zero-point 表达实数零及负值，不能将负权重直接截断为零。是否支持实际所需的非对称参数和每层范围仍需硬件确认。

在验证集上比较输出偏差、RMSE/MAE、各层饱和率和运行成本，确定待部署方案；最终测试集用于一次固定方案的评估。若误差明显增大，先调整分段、范围或保留敏感层 FP32，不自动重新训练或改换模型。

具体校准参数、124 分支对照和验证结果见[真实权重量化与混合诊断](rul-quantization-validation.md)。两个回归头样条分支的电脑验证预测最大偏差约 0.01163 个周期；六个真实权重 NPU 夹具通过 1 LSB 对照。分段运行时完成 184 窗混合回放，相对 FP32 最大预测偏差约 0.03055 个周期，CMA 首窗后保持 1204224 字节。当前只量化两个回归头样条分支，新增分支仍需真实层与完整验证集对照。

## 第四步：完整模型与应用验收

| 范围 | 验收内容 |
|---|---|
| 模型身份 | 相同检查点、权重、输入预处理、标签单位及固定推理模式 |
| FP32 重构 | 原始参考容差逐窗通过；量化误差单独报告，不放宽 FP32 移植检查掩盖偏差 |
| 量化精度 | 固定方案报告相对原模型偏差、测试集 RMSE/MAE 与退化量；允许退化阈值由应用要求确定 |
| 硬件执行 | 每个 NPU 分段核对实际计算层后端、运行库版本和执行事件；CPU 段明确标出 |
| 整体性能 | 同输入、同系统、同配置下比较 CPU 与混合方案；预热后统计平均、P50/P95、峰值内存和 CMA 使用 |
| 计时边界 | 包含量化、排列、同步、复制、CPU/GELU 和 NPU 段；模型构建/加载另报 |
| 应用接入 | 明确数据集回放入口、预测频率、输出单位，再对接 PS 接口 |

现有 CPU 平均约 0.199 秒/窗是可复现基线的诊断结果。是否需要进一步加速，以及可接受的精度退化和预测周期，仍由应用验收要求决定。
