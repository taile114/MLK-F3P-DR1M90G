# 单故障分类与分级

本文规定当前单故障模型的训练标签、五分类解码、所选故障分级及本地调用。网络标识为 `fault_mtl_f3p_cnn2d_single_v3`，任务为 `bench_fault_single_v1`，分类契约为 `single_primary_fault_v1`。

## 1. 输出约定

有效输入只返回一个类别、一个等级和该类别的 softmax 分数：

| 类别索引 | 标识 | 名称 | 等级 |
|---|---|---|---|
| 0 | `normal` | 正常 | 0 |
| 1 | `overload` | 过载 | 1/2/3 |
| 2 | `undervoltage` | 欠压 | 1/2/3 |
| 3 | `overtemperature` | 过热 | 1/2/3 |
| 4 | `mount_tilt` | 电机倾斜 | 1/2/3 |

分类头输出五个 logits，取 `argmax(logits)` 作为唯一类别；softmax 用于记录所选类别分数，不再使用四个独立阈值。正常是独立训练的第五类，不强制正常运行也输出故障。

分级保留四个故障的有序等级头。类别为正常时返回 0；类别为故障时，只读取该故障的等级头，返回 1～3。其他头的等级不参与当前结果，不对四个头取最大等级。输入不可用时返回 `unavailable` 和空等级，不以正常替代。

该任务选择最可能的主故障；发生复合故障时也只报告一个主类，不提供全部故障组合。

## 2. 网络与训练

| 项目 | 规格 |
|---|---|
| 物理输入 | `base6`，六分支张量与短上下文特征配置保持一致 |
| 分类输出 | `class_logits[B,5]` |
| 分级输出 | `severity_scores[B,4]`、`grade_logits[B,4,2]` |
| 最终解码 | `class_index[B]`、`selected_grade[B]` |
| 最后一层 | Linear 128→9，前五项为分类 logits，后四项为等级分数 |
| 参数量 | 257137，含 720 个固定补齐权重 |
| Conv/Linear 权重 | 256416 |
| 计算量 | CNN MAC 12386304/窗，Linear MAC 259744/窗 |
| 分类损失 | 五类交叉熵，竞争学习唯一主类 |
| 分级损失 | 只对真实主故障计算有序分级损失，正常样本不监督故障等级 |

`FaultMTL(classification_mode="single_label", temperature_isolation=True)` 构建本网络。训练和推断从已冻结的 `config.yaml` 或 checkpoint 读取该选项；加载时检查架构、任务、类别顺序和分类模式，不能将多标签权重直接作为单故障权重使用。

正常、过载、欠压、倾斜的原始分类 logits 不读取温度值及温度有效位/年龄；过热 logit 单独读取温度。机械故障的等级头同样屏蔽温度。五类共享 softmax 归一化，因此温度变化仍可能使过热成为最高类别；机械类原始 logits 和机械类之间的排序不直接随温度通道变化。

## 3. 标签与数据划分

主类按操作者确认的原文件名生成，暖机为正常 0 级，四类故障按 g1/g2/g3 分级。`class_target` 为 0～4 的单个整数，所选故障的等级为 1～3。非选中类表示“没有选作主故障”，不表示已独立测量证明其物理状态正常；源多标签中的未知掩码和依据保存在窗口清单的来源字段中。

[prepare_single_class.py](fault_mtl/prepare_single_class.py) 复用已冻结的物理特征、水平参考、标准化参数和时间划分。六个输入张量字节不变，仅创建新的主类标签、版本清单和窗口 ID：

| 数据集 | 窗口 | 正常 / 过载 / 欠压 / 过热 / 倾斜 |
|---|---:|---|
| train | 1063 | 183 / 225 / 239 / 174 / 242 |
| valid | 360 | 66 / 75 / 80 / 58 / 81 |
| test | 360 | 66 / 75 / 80 / 58 / 81 |

数据缓存为 [active_selection_single_v1](cache/active_selection_single_v1/dataset_manifest.json)，主类标签见 [primary_labels.csv](cache/active_selection_single_v1/primary_labels.csv)，时间块见 [split_blocks.csv](cache/active_selection_single_v1/split_blocks.csv)。每份均包含全部 26 段记录；集合间物理输入时间及 DMA 块不重叠，参考与标准化仅来自 train。四秒有效上下文、每分钟保存缺口及原生块频谱的定义见 [快速训练说明](快速训练说明.md)。

test 是同批记录内部留出，并已用于模型开发对照，不是全新独立重采。单故障本轮训练只用 train 更新参数、valid 选轮数；test 不用于本轮梯度或早停。

## 4. 当前训练结果

RTX 4060 Laptop 上完成 25 轮 FP32 开发训练，batch=32，seed=42；最佳为第 21 轮。冻结该权重后，test 结果为：

| 指标 | 结果 |
|---|---|
| 五分类准确率 | 100%，360/360 |
| 仅故障窗口的分类准确率 | 100%，294/294 |
| 故障分类及对应分级同时正确 | 98.64%，290/294 |
| 含正常的类别与等级同时正确 | 98.89%，356/360 |
| 每窗报告的故障类别数 | 正常为 0 个故障；异常为 1 个故障 |

权重为 [best.pt](runs/active_selection_single_v1_seed42/best.pt)，结果见 [summary.json](runs/active_selection_single_v1_seed42/summary.json)、[test/metrics.json](runs/active_selection_single_v1_seed42/test/metrics.json) 和 [五类混淆矩阵](runs/active_selection_single_v1_seed42/test/confusion_matrices.json)。96 项测试及数据不变性证据见 [single_class_verification.json](single_class_verification.json)。这些是同批台架数据的开发成绩，权重保持 `final_training=false,acceptance_verified=false`。

## 5. 推断调用

在本目录运行，索引 84 的实际输出为过载 2 级：

```powershell
$python = 'E:\competion\code\.venv\Scripts\python.exe'
& $python -X utf8 -m fault_mtl.predict `
  --checkpoint runs/active_selection_single_v1_seed42/best.pt `
  --dataset cache/active_selection_single_v1 --split test --index 84
```

输出包含一个 `fault` 和一个 `grade`，不包含多故障列表。实际结果摘录：

```json
{
  "valid": true,
  "fault": "overload",
  "fault_name": "过载",
  "grade": 2,
  "confidence": 0.9998445510864258
}
```

Python 使用 [predict_cached](fault_mtl/predict.py) 直接返回此字典。实时程序取得与冻结预处理一致的标准化六分支输入后，可调用模型和 `decode()`，读取唯一的 `class_index`、`selected_grade`；缓存工具中的标签不参与推断输入。

## 6. 重建与训练

使用新输出目录。物理特征缓存已存在时不需要重新切窗：

```powershell
& $python -m fault_mtl.prepare_single_class `
  --dataset cache/active_selection_exploratory_v2 --output cache/single_rebuild

& $python -m fault_mtl.train `
  --dataset cache/single_rebuild --config cache/single_rebuild/config.yaml `
  --device cuda:0 --batch-size 32 --epochs 25 --output runs/single_rebuild_seed42

& $python -m fault_mtl.evaluate `
  --checkpoint runs/single_rebuild_seed42/best.pt `
  --dataset cache/single_rebuild --split test --bootstrap 0 `
  --output runs/single_rebuild_seed42/test
```

本配置的[独立离线 F3P 测试包](../deploy/README.md)使用 train 1063 窗校准 CNN，并冻结 test 特征、FP32/整数参考和严格 Alnpu 计划。[板端复核](../deploy/BOARD_TEST.md)已完成四卷积 NPU 的 360 窗回放、逐卷积整数审计及约 19.1 倍网络前向加速对照。通用 `fault_mtl.export` 对原生块探索预处理的限制保留，实时预处理和上位机接入另行实施。多标签对照模型和其数据、权重保留在独立目录。
