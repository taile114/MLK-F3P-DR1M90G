# base6 故障诊断数据采集执行规程

本文规定现有六路物理量的现场记录、状态驻留时间、正常暖机过程、故障切换和交接要求；网络、标签与验收口径以[设计方案](设计方案.md)为准。

任务采用 `bench_fault_sim_v2` 演示标签，四类为过载 `overload`、欠压 `undervoltage`、外壳过热 `overtemperature`、安装倾斜异常 `mount_tilt`。温度规则为 `case_temp_35_40_45_v1`：壳温 35～不足 40 ℃为轻度、40～不足 45 ℃为中度、45 ℃及以上且未越过试验上限为重度；低于 35 ℃不触发该类标签。倾斜使用相对规定水平安装面的实际角度，3/6/10°为候选分界（REF），规则为 `mount_tilt_3_6_10_ref_v1`，须在正式采集前验证并冻结。其他模拟故障按已审核植入工艺定义。三级表示项目植入强度，不要求造成真实损坏；模拟分界与实际设备限制分别记录。

## 1. 采集范围与时间定义

输入固定为机身振动 XYZ、电流、转速、外壳温度。所有通道同时连续记录，保持原生采样，XYZ 必须保留重力分量，不在采集或原始导出时高通/去均值。ADXL345 刚性固定在机身并随平台倾斜；模型从其原始值派生姿态，不要求增加在线倾角传感器。采集程序默认的 60 秒文件分段只是存储边界，不是训练样本或独立试验边界。

| 时间或区间 | 定义与用途 |
|---|---|
| 操作时刻 | 调供电、加减制动负载、启停或停机调整安装倾角的实际时间 |
| 过渡区间 | 操作后状态尚未确认、等级正在跨界或恢复未完成的时间；单独保留 |
| 状态驻留区间 | 四类故障的存在状态与各自等级均可审核，且所需工况保持在规定范围内；其内的温度可以变化 |
| 固定预运行参考区间 | 按统一启动与加载工艺运行到约 15 分钟时取得的候选正常参考；同时审核温度、电流、转速及负载，不表示热平衡或安全运行时限 |
| 热平衡区间 | 固定工况下外壳温度趋势已足够平缓的区间；是健康/故障数据的一种工况，不是所有采样的前提 |
| episode | 一次经过审核的状态驻留或试验事件，关联实际工艺设置及恢复记录 |
| session / 热循环 | 同一次连续实验及相互关联的暖机、升温、驻留、冷却记录；数据划分的独立组 |

模型初版使用最近 4 秒振动及快状态、最近 60 秒慢状态，每 1 秒生成一个窗口。稳态训练主集要求整个 60 秒输入历史都在同一审核故障集合与等级区间内；故障或等级切换后，提取该主集窗口需重新满足同状态历史条件。故障发生/恢复的动态训练集另按窗口末端已确认状态标注，保留含前一状态的真实历史。

60 秒是模型回看的采样历史，不是等待电机热平衡的时间，也不是故障每次出现后必须等待的固定诊断延迟。完整历史建立后可逐秒推理，但暖机故障和发生过渡的表现仍需相应训练与测试；初版稳态数据不能直接证明该能力。历史不足或窗口包含未经验证的停机/启动阶段时，输出资格按主设计处理。

若连续合格驻留时间为 `D` 秒、步长为 1 秒且无其他质量排除，可用窗口理论上约为 `floor((D-60)/1)+1` 个，适用 `D≥60`。例如 180 秒驻留最多约 121 个窗口，实际还受边界不确定性、数据丢失和滤波有效区间影响。这些重叠窗口高度相关，不能当作 121 次独立实验。

## 2. 连续记录与后续分割

1. 为本次实验分配 `session_id`、工艺版本和记录文件夹，确认传感器位置、方向及校准版本。
2. 在电机启动前约 30～60 秒开启记录（REF），保留停机背景，标为 `stopped`。这段不充当健康运行训练样本。
3. 连续保存启动、正常运行、故障操作、状态驻留、恢复和必要的冷却过程；每项操作按统一时钟记录到秒，并保存执行依据。
4. 分别记下操作开始、状态/等级确认开始、结束操作和确认恢复的时间；边界有反应延迟或无法确认时，记录一个不确定区间。
5. 后续先依据现场记录建立审核区间，再按时间排序、拼接相关文件、筛除过渡窗口、生成训练窗口。单凭波形无法可靠还原实际故障种类及人为设置的等级，现场记录不可省略。
6. 保持原始文件完整。优先导出 `--native-csv`，标签与试验清单另外保存；不要手工删除过渡数据或只交付降频后的等间隔 CSV。

同一条连续记录可以包含多个故障或等级，只要边界明确。初版更便于核验的组织方式是一次主要改变一个因素；其他因素的真实状态同时审核。安装倾角调整必须在停机时完成，全部固定螺栓保持正常紧固，重新启动的过渡单独标注。

## 3. 正常数据的采集

正常数据覆盖冷态启动、正常暖机、固定预运行参考区间、正常调速/加载和故障恢复后的健康运行；实际能在额定条件内达到的热平衡作为可选对照。全健康要求四类模拟标签均未触发且试验通过审核，不能仅由运行分钟数决定；外壳温度低于 35 ℃只确认温度一类的正常侧，边界不确定区间另处理。

| 阶段 | 记录与使用规则 |
|---|---|
| 启动前停机背景 | 单独标 `stopped`，用于背景与传感器检查 |
| 启动/加速 | 连续保留，标为正常启动的过渡事件；初版用于动态误报评估，不直接并入稳态主训练集 |
| 正常暖机 | 转速、负载处于正常演示范围，四类模拟标签均未触发；壳温在 35 ℃以下继续上升仍可为健康，驻留满 60 秒后可按正常标签切窗 |
| 约 15 分钟的参考运行段 | 在工况合格、允许持续时间内取参考数据；不要求温度趋势已平缓，不把此时壳温直接当作正常温度上限 |
| 可选热平衡正常运行 | 仅在额定工况和允许持续时间内自然达到时采集；不为取得该数据继续长时间加载 |
| 正常调速/正常加载 | 覆盖不同允许工作点，单独记录过渡和随后的健康驻留，避免将低转速或电流变化直接学习为故障 |
| 故障恢复后 | 核验所有模拟故障均已解除；冷却时壳温仍达到 35 ℃，继续按当前温区保留模拟过热等级，不因停止加热而立即标健康 |

默认参考工艺采用统一初始条件、正常供电/调速与已核验正常负载，连续记录至约 15 分钟的参考时点（REF）。若任何设备边界或工况质量条件不满足，提前结束或调整工况，不为到达参考时点继续运行。允许条件内以第 14～15 分钟这一分钟的有效样本形成 `T_ref15`、`I_ref15`、`n_ref15` 的中位数、范围及变化趋势；记录实际取段范围。需要 2～3 分钟的正常驻留时，可选取参考时点前后满足条件的连续区间，不强制从第 15 分钟起额外等待。

参考工艺需按初始壳温、环境、正常负载及调速工作点分别建立。首轮争取 3 次独立重复，汇总同一工况的范围；每次也记录制动器初始热状态与冷却条件。后续故障比较须核对实际工作点与初始条件，不能仅因旋钮位置相同就认定负载相同。

### 3.1 参考观测与标签边界

| 已报告的现场观测 | 数据解释 |
|---|---|
| 电机外壳约 15 分钟为 28±2 ℃，约 30 分钟为 40 ℃ | 两时点之间仍有明显升温；28±2 ℃只是当前工况、时点的观测范围，不是传感器误差、统计置信区间或通用正常上限 |
| ADS1115 检测的电机电流下降，转速上升 | 运行点存在变化，需要核验负载、调速、供电及测量漂移；尚不能确定具体原因 |
| 磁粉制动器发烫，型号/励磁控制方式未明确 | 制动器温度与电机壳温是不同量；实际制动器温度、允许连续耗散、表面温度及工作制均为 TBD |

`T_ref15≈28±2 ℃` 可作为该工况的候选正常比较背景。有效壳温按下表标注，使用 `label_basis=temperature_demo_threshold`；测量死区宽度按校准结果冻结。运行到第 30 分钟或超过 15 分钟本身不是标签依据，必须使用真实温度跨界时刻。

| 壳温 T | 温度类别 | 等级 |
|---|---|---|
| `T<35 ℃` | 未触发 | 0 |
| `35≤T<40 ℃` | 轻度模拟过热 | 1 |
| `40≤T<45 ℃` | 中度模拟过热 | 2 |
| `45 ℃≤T≤T_stop` | 重度模拟过热 | 3 |

`T_stop` 为实际试验温度上限，保持 TBD 并在采集前核验，45 ℃不是允许无限加热的依据。测量不确定区间跨过 40/45 ℃时等级设未知；35 ℃附近连存在状态也不确定时，同时屏蔽类别。升温、预热后驻留与冷却都用同一分级表。

参考温度不作为每条记录的自适应零点，当前网络仍使用绝对壳温和训练集统一标准化。`T_ref15/I_ref15/n_ref15`、运行时长和工艺档位只用于试验审核/分组，不成为额外预测输入；模型也不因尚未运行满 15 分钟而停止暖机阶段的诊断。

外壳与绕组之间存在热传导及温差，表面温度不等于绕组温度，依据见 [Nidec 热阻说明](https://www.nidec.com/en/products/small-precision-motors/technology/motor/glossary/item/thermal_resistance/)。本项目按 35/40/45 ℃定义外壳状态模拟，不据此宣称内部绕组同温或已经损坏；壳温也不代替制动器自身的温度核验。

每个正常工作点均需覆盖冷态运行、正常暖机与合格的预运行参考背景；不要求每次故障试验都从完全冷机开始，但必须记录初始壳温、环境情况和相互关联的热循环，避免“健康全是冷机、故障全是热机”。

### 3.2 制动器热负载与工况漂移

先核验制动器型号、允许连续耗散功率/工作制、冷却方式和励磁电源类型，再确定正常加载工艺；当前发烫且工作点漂移的加载条件不直接冻结为健康基线。未核验前暂停在该加载条件下继续延长运行，按设备规程卸载、停机及冷却，不以触摸判断是否符合温度限值。

恒压励磁时，线圈升温引起的电阻与励磁电流变化会影响制动力矩；这可作为电机电流下降、转速上升的一项待核验解释，不是本平台已确认的故障结论。原理依据见[三菱电机：试验机用磁粉制动器的选型和供电说明](https://www.mitsubishielectric.co.jp/fa/products/drv/tencon/pmerit/case/whats/whats_tencon_ap03.html)。需区分电机电流与制动器励磁电流，不从电机电流直接反算已知制动力矩。

即使调速/制动旋钮未动，也要核对每个 2～3 分钟驻留区间内的转速、电流与负载证据。允许漂移范围按工作点与等级间隔在先导试验后冻结，当前为 TBD；超出时标 `load_drift/suspect` 审核标志，不加入第五个故障类别。负载或等级无法确认时使用主设计的未知掩码，不沿用设定档位强行打健康或固定过载等级。

### 3.3 暖机时的过载、欠压和安装倾斜

要覆盖正常暖机过程中发生故障的使用场景，故障采样同样必须覆盖冷态运行前段、正常暖机中段和合格的预运行参考背景，热稳态仅在可取得时增加。只采完整健康暖机、再在热机上采全部故障，不能作为暖机故障可识别的证据。三类非过热故障的各等级按热背景核对支持数，并在相近转速/负载背景下设置健康对照，具体矩阵见[设计方案 §7.4](设计方案.md#74-暖机阶段的故障覆盖)。

1. 在一个工作点先选可控等级，比较不同热背景下的故障，每条件争取 3 次独立重复（REF）；确认差异后补齐各等级、工作点及验证/测试覆盖。
2. 过载和欠压可按已批准工艺在暖机时设置，连续保存操作前后与恢复；记录实际事件边界，不等待热平衡后才标故障。
3. 安装倾斜在停机时设置并核验实际角度，从故障已存在的启动过程连续记录；另采不同初始壳温的启动。已倾斜启动时沿用经核验的水平基准，不重新归零；运行中改变倾角的事件能力另作专项验证。
4. 壳温低于 35 ℃的正常温升不触发本项目过热标签；达到 35 ℃后按三级温区审核，若同时存在其他模拟故障则形成复合标签。热背景和故障等级是两个独立标注维度。
5. 启动后已有充分历史的暖机故障，以及采集历史不足 60 秒时的早期故障，分开验收。早期记录仍保留；如需即时识别，按主设计另行验证短历史模式，不能用热机数据或重复读数补齐。

每次故障试验都重新从完全冷机开始并非默认流程，但完整矩阵中必须包含独立的冷态/暖机故障试验。正常的 3 次暖机循环用于健康对照，不能同时算成某类故障的 3 次暖机重复。

## 4. 单次状态驻留时间

下表指**每个故障类型的每一个等级、每个工作点、每次独立设置**的连续合格驻留时间，不含启动、调整、过渡、升温到档和冷却时间。所有时长均为本项目 REF，不是达到 90%/85% 的样本量保证，也不是设备允许持续运行时间。

| 状态 | 单次驻留建议 | 实施要求 |
|---|---|---|
| 正常稳态/正常暖机 | 2～3 分钟，优先 3 分钟 | 多个允许转速与背景负载，覆盖不同初始热状态；完整正常暖机记录另保留 |
| 过载一级/二级/三级，各级分别执行 | 2～3 分钟，优先 3 分钟 | 负载与等级可信；同步检查是否进入过热，温度不必达到平衡 |
| 欠压一级/二级/三级，各级分别执行 | 2～3 分钟，优先 3 分钟 | 已执行供电植入条件可审核、调速与制动负载受控；无实测电压时按主设计标明代理依据 |
| 安装倾斜一级/二级/三级，各级及方向分别执行 | 2～3 分钟，优先 3 分钟 | 停机调整共同安装面并核验参考角度，启动过渡后才计入驻留；独立重复需恢复水平、重新设置角度，正常紧固与轴线关系保持一致 |
| 外壳过热一级/二级/三级，各级分别执行 | 在该等级区间内争取 3～5 分钟 | 升温或降温跨越等级时切分；温度无需完全平衡，但整段必须留在同一已审核等级内 |
| 选定复合故障组合及等级配对 | 争取至少 3 分钟 | 整个 60 秒输入历史内所有标签均保持可信，另做独立重复 |

首个 60 秒用于建立该状态的完整输入历史。例如连续维持 3 分钟，约有后 2 分钟可生成稳态窗口；此前的健康历史不能代替故障后的完整历史。恰好维持 60 秒时理论上只有约一个完整窗口，不适合作为常规采集计划。

温度各级按 35/40/45 ℃分界执行，停留在同级温区的运行数据可用于分类和分级。若同时出现负载变化，温度标签可在可信时保留，负载/其他类别不确定则分别设掩码；不要为取得纯过热数据把其他故障强行标为不存在。

上述时长用于稳态主集。故障刚发生的前 60 秒也完整保留，供事件训练与延迟评估，不应因尚未形成同状态窗口而丢弃或标成健康。

如果某个重等级或加载工况允许持续时间不足 60 秒，应保留原始短记录并标为该初版稳态 profile 不适用；后续需另定短窗/动态模型或调整试验等级。不能拼接不连续短段、复制数据来补满历史，也不能为凑时长延长故障。磁粉制动器的允许持续时间受力矩、转速、散热和额定工作制共同约束，依据见 [Magtrol 选型与功率说明](https://www.magtrol.com/product/powder-brake-dynamometers-pb-series/)；具体执行值以本机制动器和电机资料为准。

## 5. 独立重复与总量

### 5.1 首轮先导数据

选择一个中间正常工作点，覆盖健康和 4 类×3 级共 13 种状态。每种状态争取 3 次独立恢复/重新设置后的驻留记录。过载、欠压和倾斜每级合计约 6～9 分钟；过热每级合计约 9～15 分钟，不包括到达该级所需的时间。倾斜该计数只包含一个已声明方向；按实际使用范围增加前后/左右方向，每增加方向均需另核对支持数，不能把同一角度连续切片当独立重复。

按全部 39 次状态驻留都取 3 分钟计算，驻留原始记录约 117 分钟；热态驻留延长、暖机、基线、调整和冷却会增加实际时长。先导数据用于检查通道质量、标签与可分性，不能据此承诺最终指标。

同一升温过程中顺序经过三级，可以分别取得三个等级的区间，但它们属于同一热循环。对每级实现 3 次独立热重复，需要多个独立热循环；不能把同一次长热记录切成三段作为三次重复。

### 5.2 正式数据参考量

按主设计的起点，每个“状态×工作点”至少 10 次独立 episode、至少 3 个正常工作点。因此对一个指定非热故障等级，驻留记录约为 `3×10×(2～3)=60～90` 分钟，优先按 90 分钟安排；一个过热等级约为 `3×10×(3～5)=90～150` 分钟，升温/冷却另计。

完整基础矩阵为 `13×3×10=390` 次状态驻留，复合故障、启动/调速对照另计。应跨日期、初始温度和独立工艺设置分布，而非一次连续采完。同一 session、热循环和相邻分段统一放入训练、验证或测试中的一个集合；切窗由后续预处理完成，现场不得逐文件随机分配数据集。

对基础矩阵另核查各类/各级的热背景覆盖，不以达到 390 次总数替代暖机故障采集。未覆盖的类别、等级或阶段标为待采，按真实缺口增加实验；不同阶段的记录仍按完整 session/热循环分组，不能互相泄漏到训练与测试。

## 6. 故障试验的连续记录流程

典型非热故障试验如下，时长为 REF：

```text
开启记录并保留背景
→ 启动/进入正常工作点
→ 已审核健康基线约 2 分钟
→ 故障植入操作及过渡（单独记录）
→ 已审核目标故障/等级驻留约 3 分钟
→ 解除操作及恢复过渡（单独记录）
→ 确认四类均恢复正常后，再留健康记录约 2 分钟
→ 停止并核验末段落盘
```

这一次约包含 7 分钟的基线与驻留，加上实际启动、过渡和恢复时间。恢复未完成时保持真实标签；尤其卸载不等于壳温恢复正常。停机调整倾角的时间不计入运行驻留。

过热试验连续记录正常、升温、各级停留、卸热及冷却，不应只截取最高温的一段。每次跨等级单独记录边界；若某一级停留不足 60 秒，该级本次记录不足以形成初版稳态主集，不向前后扩张标签凑齐时长。

### 6.1 吹风机加热与预热后采样

过热的每次驻留采样不必都从正常温度升上去。完整升温路径与目标温区驻留分开组织：

1. **完整热循环**：电机在规定运行工况下，从正常温度连续记录升温、35/40/45 ℃跨界、各级驻留与冷却，用于事件训练和检测/等级切换延迟评估；每个循环单独编号。
2. **目标温区驻留**：先将壳温调整至指定温区，再在电机运行、转速/负载及测量有效条件下连续记录 3～5 分钟（REF）。例如轻度可选约 37 ℃，中度可选约 42 ℃；重度选 45 ℃及以上且低于已核验上限的温度。无需每段前都降回正常温度。
3. **停机预热后启动**：可保留该方式，但启动过渡另标，完整运行历史建立后再生成稳态主集；不能将停机加热段直接当作健康运行或运行故障主集。
4. **同温区冷却样本**：停止热风后仍在某等级温区的运行数据继续按该级标注，直至跨界；同一热循环的升温与冷却记录放入同一数据划分组。

使用吹风机时，优先可控制地到达目标区间并保留驻留，不快速连续穿过全部等级。若 35～40 ℃只经历十几秒，本次轻度没有足够同级历史形成稳态窗口；该短段仍保留供事件训练。允许温度在同级区间内缓慢变化，不要求严格恒温。

固定壳体测点、温度传感器和振动传感器安装。避免只向温度测头吹热风而壳体尚未达到目标；接触探头保持贴合，非接触探头保持测距、视场和表面条件，具体方式按实际硬件确定。热风作用位置与距离可调，但记录档位、距离、开关时刻及温度趋势，不碰动机身或探头制造振动。

在同一温区内同时保留热风开启和关闭后的有效数据，增加低于 35 ℃的匹配气流对照；不按“吹风机开启”直接赋故障标签。`thermal_path=heating/hold/cooling/preheated_start`、热源及开关信息仅用于审核、分组与专项评估，不输入模型，避免模型依赖加热器声音、气流或安装扰动。吹风机加热的是外壳模拟状态，不要求加重制动器负载，也不表示内部绕组达到相同温度。

### 6.2 安装倾斜的设置、分级和记录

安装倾斜表示规定安装基面相对水平基准的姿态偏离，不等同于通用机械损伤等级。候选规则与标签如下；实际允许倾角和持续时间须先按机构、电机、制动器及连接方式核验，未核验时不执行相应档位。

| 状态 | 独立参考角度 `theta_ref_deg`（REF） | 标签字符串 |
|---|---|---|
| 倾斜正常侧 | `0≤θ<3°` | 仅确认第四类为 0，全健康须其他三类也正常 |
| 轻度 | `3°≤θ<6°` | `mount_tilt_g1` |
| 中度 | `6°≤θ<10°` | `mount_tilt_g2` |
| 重度 | `10°≤θ≤theta_stop_deg`，允许上限为 TBD | `mount_tilt_g3` |

3/6/10°分别归入轻/中/重；规则 `mount_tilt_3_6_10_ref_v1` 的状态为 REF，正式采集前验证各级可重复性、参考误差与允许范围后冻结。参考误差跨 6/10°时等级设未知；跨 3°且存在状态不能确认时类别也设未知。优先在等级内部、远离边界处采驻留，边界测试另行组织。参考角度不能由模型估计角或振动强弱倒推，垫块高度与目标档位也不能替代实际角度核验。

执行顺序：

1. **核验固定与共同安装面**：ADXL345 与机身刚性连接，电机和磁粉制动器优先使用共同可锁定的刚性倾斜支架；保持正常紧固、轴线关系及传感器相对机身的方向。正常和倾斜对照使用相同支架，不通过松退螺栓或单独抬起电机制造松动、不对中。
2. **建立水平参考**：用独立水平尺/量角装置核验规定安装面，完成 ADXL345 零偏/增益检查，停机静止记录 5～10 秒（REF）形成参考重力向量，保存 `gravity_reference_id`、参考测量、安装照片与校准版本。只有安装改变或核验失败才重建基准，不把每次启动的当前姿态自动归零。
3. **记录正常运行对照**：在已核验水平、正常供电/负载与壳温条件下连续记录 2～3 分钟，检查静止与运转时估计角度偏差；保留不同转速和热背景对照。XYZ 原生值保持重力分量，不能只交付 AC RMS、模长或去均值波形。
4. **停机设置目标角度**：选择已核验允许范围内的等级内部角度和规定方向，锁定支架，参考测量实际角度及误差，记录设置和确认时刻。调整时保持记录，停机/手动调整段单列；不作为运行故障驻留。
5. **启动并采同级驻留**：启动过渡和测量稳定后，各等级×方向×工作点争取 2～3 分钟，优先 3 分钟；参考角度在驻留前后核验，波动或漂移无法确认的时间设未知。模型稳态主集仍需完整 60 秒同状态历史，不要求每档重新暖机 15 分钟；冷态/暖机覆盖按 §3.3 另核对。
6. **恢复与独立重复**：停机恢复经核验的水平安装，重新启动并记录恢复对照，再重新设置角度；每条件先争取 3 次独立设置。相互关联的启停、驻留和热历史属于同一 session，不因重新调角就自动成为可跨训练/测试的独立组。
7. **方向与边界专项**：按目标使用范围覆盖前、后、左、右方向，相同角度幅值采用相同等级；先导可从单一方向起步，但只能报告该范围。需声称新方向泛化时，预先留出完整方向及独立 session 评估。初版不包含运行中改变倾角的能力，不能用手扶运行中的电机补采该事件。

交接时同时提供原始 MLKC、参考角度记录及 `mount_tilt_g1/g2/g3` 或四类数组标签。参考量角装置仅用于标注和核验，不接入 `base6` 网络输入。模型姿态支路从高通前 XYZ 的过去 4 秒均值计算，不能把参考角度写入传感器列；姿态估计、因果性和质量条件见[设计方案 §4](设计方案.md#4-输入窗口与预处理)。

### 6.3 既有数据与实现的适用范围

首批自然升温记录没有倾斜植入或独立水平/角度核验，原始文件和 v1 切片保持完整。温度子任务标签可保留；用于 `bench_fault_sim_v2` 时另建审核清单，没有证据的第四类为 `present=null,class_mask=0,grade=null,grade_mask=0`，不能将 `mount_looseness=0` 自动改成 `mount_tilt=0`。

[model/](model/README.md) 现有代码及 [segment_capture.py](tools/segment_capture.py) 对应 v1 标签，不直接执行本规程的 v2 姿态设计或标签适配。v2 实现、缓存与运行包应使用独立版本并核对类别顺序，不能仅改显示名称后继续训练或导出。

## 7. 现场检查与事件记录

### 7.1 采集前及采集中

1. 确认六路真实采样有效：振动来自 DMA，电流已标定而非默认零，转速未接近记录饱和值，壳温有真实更新。
2. 振动探头相对机身的位置、XYZ 方向、紧固方式、线缆固定及温度探头接触方式保持一致；确认 ADXL345 随机身倾斜，原生 XYZ 含重力且水平参考有效。正常对照保留与故障试验相同的辅助装置布置。
3. 一次主要改变一个因素，记录其他因素；不同故障覆盖相近的允许转速/负载范围及冷热状态。固定旋钮而电流/转速持续漂移时，先审核实际负载及标签有效性。
4. 检查电机与制动器允许工作范围、数据丢块/饱和、磁盘空间、记录错误及保护动作；动作或数据异常时写入事件记录，不用模型输出代替标签或停机依据。
5. 不在正式记录中进行电流归零或更改标定；如必须操作，单独标出影响区间，并重新确认健康基线。
6. 采集结束等待末段落盘，备份原始 MLKC、对应 MLKL、试验记录、配置及校准来源；保存对应解密口令，勿将其写入公开试验表。

### 7.2 事件记录最小字段

| 字段 | 现场记录要求 |
|---|---|
| `session_id / episode_id` | 连续实验与事件身份，关联全部原始分段 |
| 统一时间/相对时间起点 | 记录日期、时区和时钟偏差；可同时记相对秒数 |
| 操作开始、确认状态开始、状态结束、确认恢复 | 分别填写到秒；不确定边界写区间，不能事后凭波形猜测 |
| 四类状态及各自等级 | 正常也需核验；不确定项填未知 |
| 设定与初始条件 | 调速位置/目标工作点、制动器档位、供电档位、共同安装面与紧固状态、初始壳温、环境条件 |
| 倾斜参考 | `theta_ref_deg`、`theta_ref_uncertainty_deg`、`tilt_direction`、支架编号 `tilt_fixture_id`、参考量角装置/校准来源及前后核验时刻；只作标签/分组 |
| 水平基准 | `gravity_reference_id`、规定水平面的独立核验记录、静止参考段、三轴校准版本与安装照片；参考向量供预处理使用，ID 不输入网络 |
| 预运行参考 | 实际参考取段起止、`T_ref15/I_ref15/n_ref15` 统计、初始热条件与漂移审核结果；只作元数据 |
| 热背景与事件方式 | `thermal_phase`：冷态运行/正常暖机/预运行参考/可选热稳态；记录是故障已存在的启动还是运行中故障出现，仅作审核与分组 |
| 标签依据 | 参考测量、标定或工艺代理记录及版本；无实测电压不填写虚构读数 |
| 演示规则版本 | `task_definition=bench_fault_sim_v2`、`temperature_rule=case_temp_35_40_45_v1`、`tilt_rule=mount_tilt_3_6_10_ref_v1`（REF）；温度/角度分界、测量死区、实际试验上限及正式规则冻结状态 |
| 加热路径与方式 | `thermal_path`、自然/外部加热、吹风机档位/距离及开关时间；只作审核与分组，不作为网络输入 |
| 异常与变更 | 保护/重启、丢块、饱和、探头移动、标定变化、风冷变化等 |

交接时提供完整原始记录、标签库、事件表与工艺/校准信息。后续分割可以自动化，但故障类型、等级边界与复合状态仍须依据现场事实审核。
