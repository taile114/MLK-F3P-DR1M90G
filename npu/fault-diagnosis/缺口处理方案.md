# 采集缺口的数据使用与处理方案

本文规定首批自然升温记录的缺口处理建议，区分原始数据保存、探索训练和正式验收。原始记录、派生切片及既有 0.5 秒连续性筛查结果保持不变，来源见[首批数据说明](首批数据说明.md)。

当前 26 段故障/暖机记录已有独立的[原生块短上下文训练配置](model/快速训练说明.md)：保留每分钟保存暂停造成的时间缺口，逐 DMA 块提取频谱，以有效位和年龄表达状态缺失；使用训练侧正常水平参考，完成 train/valid/test 三分与 GPU 开发训练。该配置使用四秒有效上下文，并将更早慢状态标为无效；连续波形和完整 60 秒历史的正式质量结论单独保留。

## 1. 使用结论

现有记录可用于温度规则基线、温度分类/分级子任务和数据流程验证。它只有一次自然升温，包含正常、轻度、中度，尚未覆盖重度及其他故障正例，也没有独立实验组；不能据此训练并验收完整的四故障三级目标。

连续性筛查不通过不等于所有数据作废。此前的“0 个通过窗口”指当前严格质量规则：最近 60 秒电流/转速历史中出现一次超过 0.5 秒的缺口即剔除整窗。0.5 秒是设计初值，不是通用机器学习定律。若改用缺失感知的预处理，应建立单独规格和清单并通过独立验证，不把原有失败结果改写为通过。

## 2. 拼接与插值的边界

| 方法 | 适用性与限制 |
|---|---|
| 汇总相邻文件，保留真实时间戳与源块 | 可用于归档与区间查询；文件合并不代表采样连续，缺口仍然存在 |
| 删除缺失时间，把前后波形首尾直接接上 | 不采用；会改变时间关系，并可能在接点制造非真实冲击、频谱或转频特征 |
| 给振动缺口补零、重复末值、线性/样条插值 | 不用作缺失波形重建；缺少真实相位和冲击信息，平滑曲线不等于恢复机械振动 |
| 对慢状态填数并保留有效位与年龄 | 可作为探索候选；填数只是固定形状输入的占位或因果保持，不能将其改标为真实测量 |
| 线性插值仅用于离线展示 | 可明确标示为估计曲线，不能覆盖原生数据，也不能据此标定故障跨界真值或宣称恢复采样 |

等间隔 FFT/重采样具有采样假设；缺少一段数据时，压缩时间轴或直接调用重采样不能消除缺失，参见 [SciPy resample 的输入与采样假设](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample.html)。

## 3. 分通道处理建议

| 通道/分支 | 处理建议 |
|---|---|
| 4 秒振动主干、PSD 与幅值统计 | 选择不跨已知丢块/大缺口的原生短窗；连续块内再滤波、抗混叠与重采样。滤波跨断点重置或保留合法状态，其暂态区间排除，不把缺口两边直接相接 |
| v2 安装姿态 `mount_pose` | 从高通前原生 XYZ 计算过去 4 秒重力均值与倾角，保留覆盖率、有效位和年龄；沿用真实连续性检查。缺口占位不能视为水平，缺少有效基准或受缺口影响时不能宣称完整四类输出有效；单独姿态降级输出须另行训练/验证 |
| 4 秒 I/n 快状态 | 保留真实时间轴，按过去样本对齐；过期值附有效位和年龄，明显受缺口影响的窗口优先剔除；不把低速状态插值当成高频电流恢复 |
| 60 秒 T/I/n 慢状态 | 可研究按格标记缺失而非整窗剔除：只对实际存在的样本计算过去一秒统计量，数据不满足时效/覆盖条件的格置无效，记录实际年龄；模型已有对应掩码通道 |
| 温度标签 | 使用真实壳温与 35/40/45 ℃规则；缺口覆盖跨级时刻或测量误差无法确认时，对相应标签设未知，不从插值曲线生成精确真值 |

慢状态候选规格保持因果性。短时前值保持必须检查样本年龄，超过其门限后将标准化物理值填 0、有效位置 0、无效年龄置 1；这个 0 是缺失占位，不代表真实 0 A、0 rpm 或 0 ℃。不能使用窗口终点以后的测量值进行线上模型的双向插值。

采用有效位和时间间隔显式表示缺失，有相关时序学习研究依据，参见 [Che 等：多变量时序缺失值建模](https://www.nature.com/articles/s41598-018-24271-9)。其临床数据结果不构成本项目 CNN 的精度证据；本方案只参考缺失表示，不改用 GRU-D 网络，也不默认允许任意长缺失。

上述慢状态候选不修改 `base6` 的传感器范围或网络尺寸。每格覆盖、每通道窗口有效比例、允许缺失时长、温度跨界处理与滤波暂态仍需冻结；初始可比较逐通道有效比例 ≥95% 的候选，但不能在未训练/未独立验证前宣称合格。若最近 4 秒振动本身不可用，放宽慢历史规则也不能使完整多分支输入合格。

## 4. 本次数据的细化检查

在已选三段的 2191 个同级 60 秒候选终点上，检查其最后 4 秒振动窗口是否与估算时间轴中的间隙相交，结果如下。这里的间隙长度阈值是诊断对照，不是新的合格规格。

| 振动时间戳间隔阈值 | 全记录间隙数 | 候选终点中最后 4 秒未跨该类间隙的数量 |
|---|---:|---:|
| >0.5 秒 | 40 | 2024 / 2191 |
| >0.1 秒 | 977 | 409 / 2191 |
| >0.02 秒 | 4897 | 0 / 2191 |
| >0.005 秒 | 21613 | 0 / 2191 |

因此“避开每分钟的大缺口可留下 2024 个终点”仅代表大缺口检查，不能解释为已有 2024 个完整振动训练样本。时间轴为估算 UTC，部分短间隙可能与时间重建有关，必须继续结合源块和 DMA 序号核验。

39211 个振动块中，应用 `seq` 连续递增；诊断 `count` 有 4146 次递增大于 1 的情况。仓库 DMA 发布路径将 DMA 序号写入该字段，若实板 v2 运行程序沿用此语义，计数跳变支持进一步排查实际丢块，不能只按普通时间抖动处理。实际二进制版本与计数语义仍需对照核实。详细数值在 [gap_handling_comparison.json](data/processed/gap_handling_comparison.json)。

现阶段不生成“删除缺口拼接版”或“振动插值修复版”。现有原始归档和三段 NPZ 继续作为事实来源；温度子任务与完整六路模型的数据资格分别报告。

## 5. 采集端排查与后续验证

仓库中的 [saveSnapshot](../../host/ps-local/src/klocalwindow.cpp) 在定时回调中调用同步 `CaptureRecorder::flush`；[flush](../../host/common/capturestore.cpp) 同步执行清理、序列化、密钥派生、认证加密与写盘。它与每分钟边界附近四路共同中断的现象相符，是优先排查项；本次实板记录为 v2，不能据源码片段认定实际运行程序已确认同一根因。

后续应将采集与慢速保存解耦，例如后台写入、不可变缓冲交接及有界队列；同步记录保存耗时、队列积压、DMA 环丢块与发布间隔。仅延长分段时间不等于修复，还需检查块数/容量触发提前分段及保存耗时是否随数据量增长。

先补采一段修复后的连续正常记录，验证短间隙、计数和分钟边界，再开展多故障数据。缺失感知方案可在完整记录上人为遮去约 0.8 秒片段，与原完整输入作同权重/同标签对照；训练和部署使用相同因果预处理，测试按独立 session 留出，不能依靠本次单一升温记录同时拟合和验证。
