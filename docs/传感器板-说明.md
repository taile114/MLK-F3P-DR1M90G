# MLK-F3P-DR1M90G 传感器载板 · 说明

> 面向选题 **领域 5（设备智能运维 / 故障诊断）**。
> 本板**不控制电机**——只做三件事：给传感器小模块**供电**、把信号**引到 FPGA（PL）**、给霍尔电流模块提供**电流通路**。
> 被测电机（含电源适配器 / 调速器）是**市售整套、独立运行**，与本板**不通信**。
>
> 旧「电机板」已归档为 **`MLK-F3P-Motor`**（不再维护，见 [`docs/Motor/`](Motor/)；归档副本 `eda/archive/MLK-F3P-Motor.eprj2`）。本板从电机板重建，只保留传感器供电与信号引出。

---

## 0. 简述

```
USB-C(5V) ─ F1(PTC) ─ ► +5V ─┬─ D2(TVS) · C1(10µF) · C2(100nF)
                              └─► J2 (2×8) 给传感器模块供电
P1 / P2 (2×13) ⇄ 核心板 J12：1=+3V3 · 2=GND · 3–26=PL IO(CEP1_xP/N)
H1 (PZ1.0 4P) = +3V3 抽头（4 脚全 +3V3）
U1/U2 (2P 端子) = 霍尔电流模块的电流端（电机电源在此串联）
全板单域共地（GND，经 P1.2 / P2.2 与核心板共地）
```

## 2. 电源

```
J1.VBUS ─► F1(PTC) ─► +5V ─┬─ D2 (TVS → GND)
                            ├─ C1 10µF ∥ C2 100nF (→ GND)
                            └─ J2 奇数脚 1,3,5,7,9,11,13,15 (+5V)

R4: J1.CC1 → GND        R3: J1.CC2 → GND      (CC 5.1k 下拉 → 取 5V)
+3V3: 核心板 J12.1 ─► P1.1 / P2.1 ─► H1.1~H1.4   (3.3V 抽头)
```

- **J1 引脚**：`VBUS`=A4/A9/B4/B9 · `GND`=A1/A12/B1/B12/17 + SHELL(13–16) · `CC1`=A5 · `CC2`=B5 · D+/D-/SBU **未用**。
- **`+5V` 只给传感器小模块**：来自电脑 USB 口（典型 ≤0.9A），**不接大负载**。
- `+3V3` 来自核心板（`VCC_CEP1`），经 `P1.1` / `P2.1` 引出到 `H1`。

---

## 3. 接口

### `P1` / `P2`（2×13 排母）↔ 核心板 `J12`
| 脚 | 网络 | 说明 |
|---|---|---|
| 1 | `+3V3` | 核心板 `VCC_CEP1`（3.3V） |
| 2 | `GND` | **两板之间唯一的地** |
| 3–26 | `CEP1_1P … CEP1_12N` | **PL IO 直通**，一对一标注（可跳线接传感器信号） |

- `P2` 与 `P1` **逐脚并联**（同一组网络，`P2.1=+3V3`、`P2.2=GND`、`P2.3–26` 同 `CEP1_x`）→ 同一路 PL-GPIO 有两个对插口（备用/并接）。

### `J2`（2×8 排母）—— 传感器供电
- 奇数脚 `1,3,…,15` = **`+5V`**；偶数脚 `2,4,…,16` = **`GND`**。
- 每列（第 n 脚 +5V / 第 n 脚 GND）→ **一对 VCC/GND 抽头**，最多 8 个模块。

### `H1`（PZ1.0 4P）—— 3.3V 抽头
- 4 脚**全部** `+3V3`（来自 `P1.1` / `P2.1`）。

### `U1` / `U2`（KF301-5.0-2P）—— 霍尔电流模块电流端
- `U1.1 = U2.1 = HALL_IP_P`；`U1.2 = U2.2 = HALL_IP_N`。
- **电机电源在此串联接入**：电源+ → U1.1 → 霍尔模块 IP+ → 模块 IP− → U1.2 → 电机+（或按实际模块端子接）。

---

## 4. 接地

- 全板**单域共地**：`J1`(GND/SHELL) · `D2.2` · `C1.2` · `C2.2` · `R3.2` · `R4.2` · `J2` 偶数脚 · **`P1.2` / `P2.2`** → `GND`。
- 与核心板**经 `P1.2` / `P2.2` 共地**（**只有一个接地点**，不另拉第二根地线，避免地环）。
- PCB：GND 用**顶层 + 底层铺铜**；每个 SMD 的 GND 脚旁打**地过孔**（0.6/0.3mm）就近下地。

---

## 5. 霍尔电流模块（ACS712-20A）

- 模块为 ACS712-20A，5 V 供电，标称灵敏度 100 mV/A、零电流输出 2.5 V。OUT 应接 ADS1115 A0（单端对 GND），ADDR 接 GND（I²C 0x48）；当前 PL 读取 A0、PGA=±4.096 V、125 µV/LSB。PS 默认零点 20000、增益 1250 µA/LSB，停机归零校正实际零点。参数来源：[ACS712 数据手册](https://www.allegromicro.com/-/media/files/datasheets/acs712-datasheet.ashx)、[ADS1115 数据手册](https://www.ti.com/lit/ds/symlink/ads1115.pdf)。
- 当前 ADC 正向满量程对应约 +15.96 A；ADC 输入还须处于 GND..VDD。达到 ADC 满量程时显示 ADC 饱和，不能将模块 ±20 A 标称量程作为当前通路的有效量程。
- 模块的**电流端子**接 `U1`/`U2`；电流路径：`控制器+ → U1 → 模块 IP+ → 模块 IP− → U1/U2 → 电机+`。
- **电流很大**：额定 **5.2A**、**堵转 36A** → 必须用**粗线（≥18AWG）+ 螺钉端子**；**不得走 2.54 排母 / 杜邦线**（只能走信号）。
- 模块的**信号**（VCC/GND/OUT，小电流）才用杜邦接 `J2` 的 +5V/GND；OUT 经 ADS1115 A0 转换后，ADS1115 的 SCL / SDA 接 `P1`/`P2` 的对应 I²C IO。
- **避免堵转**，并让电源/调速器限流。
