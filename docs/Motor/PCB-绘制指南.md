# MLK-F3P-Motor · PCB 绘制指南

> 本文是已归档电机板 `MLK-F3P-Motor` 的 PCB 指南（4 层、AGND 星接、三 slug 铜 等），作为归档资料留存，不再维护；归档副本 `eda/archive/MLK-F3P-Motor.eprj2`。
> `MLK-F3P-DR1M90G`（故障诊断系统）的外设是传感器载板，画法见 [`../传感器板-说明.md`](../传感器板-说明.md)。

本文描述电机板 PCB 的实现方法。原理图、网表、接口定义与设计约束见 [`电机电源电路-说明.md`](电机电源电路-说明.md)，本文只涉及 PCB 布局与走线。

数据口径：由 LCEDA bridge 实测的网表，**128 图元（127 器件 + 1 GND 旗标）/ 377 导线 / 71 网络 / 408 引脚（已接 377 / 悬空 31 合法 NC）**。本文里所有"实测"都来自它。

## 0. 绘制前确认事项

### 0.1 U3 三个散热焊盘：确认为三个独立焊盘

`U3`(VNH5050A) 封装内的 37/38/39 为三个独立散热焊盘。

将工程 PCB 文档中全部焊盘的几何（位置、尺寸、rotation）导出并逐一核对：

| 焊盘 | 尺寸（mil） | 与相邻焊盘的间距 |
|---|---|---|
| pad 37（Slug2 = OUTA） | 128.0 × 82.7 | 37↔38 = 34.3 mil，37↔39 = 33.1 mil |
| pad 38（Slug3 = OUTB） | 128.0 × 82.7 | 38↔39 = 33.1 mil |
| pad 39（Slug1 = VCC） | 128.0 × 196.9 | — |

间距 33 mil ≈ 0.84mm，对焊接足够。因此**封装不改**，按此绘制；但三个焊盘的铜皮必须分属三个不同网络，不得连成一片（见 §5）。

### 0.2 从原理图更新 PCB（现存 PCB 数据为旧版）

工程里已有一个 PCB 文档，但其网络表过旧，网络错误：

- `U3.37`、`U3.38` 还是 `GND`（正确应是 `MOT_A_BR`、`MOT_B`）——照此绘制会把半桥输出短到地，上电即损坏；
- `U7.3`(CAN 收发器 VCC) 还挂在 `+3.3V`（正确是 `+3.3V_LDO`）；
- `R53`/`R54` 还挂在本板侧而不是传感器侧；
- 缺少 `R56–R62`、`D11`、`D12`、`D13`。

**做法**：打开原理图 → 更新/转换到 PCB（重新导入网络表），然后抽查上面这几条；确认 `U3.37=MOT_A_BR`、`U3.38=MOT_B`、`U3.39=VM_12V`、`U7.3=+3.3V_LDO` 之后再开始布局。不使用手动改 PCB 网络的方式。

### 0.3 绘制顺序

核实焊盘（§0.1）→ 重新导入网表（§0.2）→ 确定叠层（§1）→ 布置大件分区（§2）→ 铺三块 slug 铜和功率回路（§4/§5）→ 划分 AGND 岛和 R19 星接（§3）→ 布采样走线（§6）→ 逐器件摆去耦（§8）→ 铺铜/打缝合过孔（§10）→ 丝印和测试点（§11/§12）→ 按 §13 自查 → 上电前按 §15 检查。

### 0.4 总原则

**大电流回路面积最小；功率区和模拟区分开；AGND 只在 ADC 下方一点接 GND；接口串阻贴着连接器放。**

## 1. 叠层

推荐 4 层 / 1.6mm：

| 层 | 用途 | 放什么 | 不放什么 |
|---|---|---|---|
| L1 Top | 信号 + 功率 | 大电流铜皮（`VBUS_20V`/`VM_12V`/`MOT_A_BR`/`MOT_B`）、Buck 热环、H 桥三块 slug 铜、J3 串阻、模拟小信号 | 模拟小信号不得与 SW / 电机线并排 |
| L2 GND | 完整地平面 | 主 GND 整片 + 切出来的 AGND 岛（只在 R19 处连 GND） | 不被走线切碎；AGND 岛下面不得有功率回流 |
| L3 PWR/GND | 电源铜 + 第二地 | 功率半区铺 `VM_12V`/`VBUS_20V`/`+3.3V_LDO`（各块间距 ≥0.5mm）；模拟半区铺 GND 或直接禁布 | 功率铜不得伸到 AGND 岛下面 |
| L4 Bottom | 信号 + 功率 | 大件（C13/C17、L1、D2、BZ1）、底层功率铜、缝合过孔、测试点、丝印 | 关键模拟回流不得仅靠底层 |

介质厚度：L1–L2 越薄越好（建议 ≤0.25mm，使信号紧贴地）；L2–L3 用厚芯板（≥1.0mm）。SPI（≤2MHz）、CAN（1Mbps）、PWM（20kHz）均无需阻抗控制。

仅做 2 层时：底层整版铺 GND、顶层走信号与功率，GND 不得被走线切开；模拟区四周做护地环（宽 ≥1mm、每 5mm 一个过孔）；模拟走线不得跨任何割缝。代价是 Buck 和 H 桥的回路面积约翻倍、地弹与串扰变差，12bit 采集精度下降。本板精度目标为 12bit，建议采用 4 层。

## 2. 布局

### 2.1 分区

按"从连接到功率、再到精密"一个方向排：

```
板边 ───────────────────────────────────────────────
[J1 USB-C] → PD 输入区   F1 / D1 / U1 / C1–C5 / R1
                  ↓
[Buck 区]        U2 / C4 C5 C6 / R2–R7 / L1 / D2 / C10–C12
                  ↓ VM_12V 铜
[H 桥区]         U3 + 三块 slug 铜 + C13–C17 + D3
                  ↓
[电机端子区]     J2 / R8 / C16                     ← 板边（电机线出口）
[模拟采集区]     U4 → R9 / C21 → U5，C18–C25 / R10 / C31–C33 / R31 / R33 / R19 / D11
[保护比较区]     U8 / U9 / R16 / R18 / R45–R55 / C37–C40
[辅助电源区]     U10 K7805(DC-DC) / C35 / C36 C42 / U11 LDL1117(LDO) / C43 / C27 C28 / FB1 / C29 C30
[数字接口区]     J3 + R20–R36 / R55 / R59 R60      ← 板边（对插底板）
[CAN 区]         U7 / R34–R37 / C34 / D8 D9 / J4   ← 板边
[传感器口区]     J6 / J7 / J8 / F2 / D10 / C41 / R53 R54 / D12 D13  ← 板边，和电机口不同侧
[声光告警区]     BZ1(φ12 通孔) / Q1 / D6 / D7 / R42 R43 R44  ← 板边
```

要点：模拟区夹在数字接口和保护比较区之间，离 Buck 和 H 桥越远越好；所有连接器贴边；传感器口和电机端子放不同侧，插传感器时手不会碰到电机线。

### 2.2 不能相邻的器件

| 规则 | 距离 | 原因 |
|---|---|---|
| Buck（U2 / L1 / D2 / SW 铜）↔ 模拟区（U4 信号侧 / U5 / R9 / C21 / VREF） | ≥10mm，不并排，不跨参考面割缝 | SW 是 20V、20ns 级边沿的宽带噪声源；采样链 1LSB 只有 0.8mV |
| `MOT_A` / `MOT_B` / `MOT_A_BR` 铜 ↔ 模拟小信号 | ≥10mm 或用铜隔开 | 3A 电机电流的 PWM 方波（±12V 摆幅）是最大干扰源 |
| U4 的 IP 侧铜 ↔ U4 的信号侧铜 | 不得桥接 | 会毁掉 7.5/8.2mm 的隔离（§7） |
| U10（DC-DC，开关噪声源）↔ U4 / U5 | ≥10mm，中间宜隔地铜 | 开关边沿是宽带噪声源；U11（LDO，仅 0.06–0.12W）温升小，≥5mm 即可 |
| U10 的输入铜（VM_12V）/ `+5V_DCDC` 铜 ↔ `+3.3V` 静轨铜 | 分开；`+3.3V_LDO` ↔ `+3.3V` 只在 FB1 处相连 | 静轨只喂霍尔/ADC/VREF/比较器；DC-DC 开关回路面积要小 |
| BZ1（φ12 通孔蜂鸣器）↔ U4 / U5 / C25 | ≥10mm，不贴在板上 | 机械振动 + 磁/声耦合，而且它高，会挡测试点 |
| CAN（`CAN_H/L`、D8/D9、J4）↔ 模拟采样线 | ≥5mm，不并排 | 总线是外部引入的浪涌/共模源 |
| J3 的 SPI 线 ↔ PWM/INA/INB 线 | 分开走（≥3mm 或夹地） | J3 是 26 脚密排，引出方向要先规划 |
| J3 的 8 个空闲脚（6,10,12,14,16,18,22,26）下方 | 不铺功率铜，不走敏感线 | 它们物理上通向底板 PL IO |
| 三块 slug 铜之间 | ≥0.5mm（建议 1.0mm） | 焊桥连就是短路 |
| 电机回流（U3 的 GND_A/GND_B、Buck 的 PGND）↔ AGND 岛 | 不得穿过 | 功率回流进 AGND 等于直接灌进采样链 |

### 2.3 主要器件朝向

- **U4**（ACS725，SOIC-16W）：信号侧（右列 9–16 脚）背向功率区、朝向 U5；IP+（1–4）和 IP−（5–8）都在左列，让电流"U3 → IP+ → 内部 → IP− → J2"一路直着走。
- **U3**（PowerSSO-36）：`GND_A`(1,3–7) 和 `GND_B`(30–34,36) 两排朝 GND 铜；`VCC`(13,24) + Slug1(39) 朝 `VM_12V` 铜（C13/C17 那侧）；输出脚（2,8–14,23,25–29,35）+ Slug2/3 朝电机端子。
- **U2**（HSOP-8+EP）：`VIN`(2)、`GND`(7)、EP(9) 朝输入电容 C4/C5；`SW`(8) 朝 L1/D2；`FB`(5)、`COMP`(6)、`RT`(4) 朝安静的一侧。
- **U10**（K7805 模块，3 脚）：`VIN`(1) 朝 `VM_12V` 铜，`GND`(2) 就近接地，`+VO`(3) 朝 `+5V_DCDC`；紧靠 U11 放（`C35`/`C36`/`C42` 各自 ≤3–5mm）。
- **U11**（LDL1117，SOT-223）：`VIN`(3) 朝 `+5V_DCDC`，`VOUT`(2,4) 朝 `+3.3V_LDO`；功耗仅 0.06–0.12W，铜**不用**特意加大（§9.4）。
- **U5**（SOIC-14）：`AGND`(12) 朝 AGND 岛，`DGND`(7) 朝主 GND；这两个脚不要在 IC 底下直接用铜连起来。

## 3. 地

### 3.1 AGND 与 GND 的划分

AGND 一共 18 个脚（实测）：`U4.11 / U4.14 / U4.15`、`U5.12`、模拟电容（C18–C25、C31–C33）的地脚、两个分压的返回（`R31.2`、`R33.2`）、以及 `R19.1`。

其余都是 GND：功率地、数字地、J3 的地、U1/U2/U3/U7/U8/U9 的地、`U10`(2) 与 `U11`(1)。`U5.7`(DGND) 和 `R16.2` 留在 GND。

### 3.2 R19 单点星接

- 位置：**U5 正下方**，离 `U5.7`(DGND) 和 `U5.12`(AGND) 两个焊盘都 ≤5mm。这样 ADC 的两个地参考在铜上几乎同电位。
- 画法：L1 上 AGND 铜和 GND 铜分成两块，**只有一个 0603 焊盘位（R19）跨过去**；R19 两端各打 ≥1 个过孔下到对应平面。除 R19 之外，不得有任何跨缝的铜、过孔或搭接。
- 验证方法：**不贴 R19 时，量 `AGND↔GND` 必须是开路（>1MΩ）**；贴上 R19 后是 0Ω。这是"单点"唯一可客观证明的方法，已写入 §15.1 检查表。

### 3.3 AGND 岛的边界

- 岛的铜包含：U4 信号侧的地、U4/U5 全部模拟去耦电容的地脚、`R31/R33/C32/C33` 的地脚、`R19.1`。
- 外边界与主 GND 之间留 **≥0.5mm 切缝**，**L2 和 L3 同时切**（只在 L1 切、内层还连着，星接就白做了）。
- 岛内只走模拟信号（`I_SENSE`/`CS_ADC`/`VM_SENSE`/`MOT_V_SENSE`/`VREF_3V3`/`FLT`/`ISENSE_RAW`）。
- L1 的模拟走线下方必须是 L2 的岛铜，不得跨过切缝。
- 岛边缘加护地环（AGND，宽 ≥1mm，每 5mm 一个过孔），把 `VIOUT`、`VREF` 这类敏感节点围起来。
- 允许跨岛的只有岛内那几根信号和 R19；SPI、PWM、CAN、电机线、`+3.3V_LDO` 都不得跨岛。

### 3.4 禁止做法

1. 数字回流不得进 AGND：J3 的地、SPI 地、CAN 地、蜂鸣器地、Buck / H 桥回流全走主 GND。
2. AGND 不得第二点接地（包括内层、包括"过孔墙"）。
3. 模拟信号不得在岛内或岛边换层。
4. 不得把 `U5.7`(DGND) 和 `U5.12`(AGND) 在 IC 底下直接连铜。
5. `U4` 的 9 / 16 脚保持悬空——不铺铜、不走线、不加测试点（为了维持爬电距离）。

## 4. 大电流回路与铜宽

### 4.1 四条关键回路

| 回路 | 组成 | 目标 | 怎么画 |
|---|---|---|---|
| Buck 输入热环 | C4/C5 的 VBUS 端 → `U2.VIN`(2) → 内部高边 → `U2.SW`(8) → D2（续流）→ 回 C4/C5 的地端 | 环路面积 ≤7×7mm，线宽 ≥1.0mm 或铺铜 | C4/C5 和 D2 的地端共用一块 PGND 铜，不得绕到主平面远端；C4/C5、U2、D2 摆成"品"字 |
| SW 节点 | `U2.SW`(8) ↔ `L1.1` ↔ `D2.2`(K) | 铜面积 ≤4×4mm，不铺大面积 | 做一小块粗短线；L1 和 D2 紧邻；下方 L2 是完整 GND；SW 铜下面不得穿任何信号 |
| H 桥环路 | C13/C17(VM) → `U3.VCC`(13,24)+Slug1(39) → OUTA/OUTB → 电机 → `U3.GND_A/B` → 回 C13/C17 负极 | 环路最短；C13/C17 离 U3 的 VCC/GND 脚 ≤10mm | C13/C17 的地端单独做一块 PGND 铜，直接回到 U3 那两排地脚，不得绕到板边再折返 |
| 电机端子 + 缓冲 | `J2.1/2.2`；`R8`(100Ω)+`C16`(10nF) 跨 `MOT_A`–`MOT_B`；`D3` 双向 TVS 跨同样两点 | 三者都贴 J2（≤8mm） | R8 和 C16 相邻摆放（各 ≤3mm）；D3 紧贴端子（本体 6.9×5.9mm，不挡电机线） |

### 4.2 铜厚、铜宽、过孔

外层建议 **2oz（70µm）**；只能 1oz 时靠铺铜宽度补。单线最小宽度（IPC-2221，ΔT=10°C）：

| 网络 | 电流 | 1oz 外层 | 2oz 外层 | 1oz 内层 | 本板做法 |
|---|---|---|---|---|---|
| `VBUS_20V` | 2A 连续 / 3A 峰 | 0.77mm | 0.39mm | — | 铺铜 + C1/C2/C4/C5 |
| `VM_12V` | 3A 连续 / 5A 峰 | **1.35mm** | **0.67mm** | 3.50mm | 双面铺铜 + 过孔阵列 |
| `MOT_A_BR` / `MOT_B` / `MOT_A` | 3A 连续 / 5A 峰 | 1.35mm | 0.67mm | — | 铺铜，2oz 优先 |
| 端子到 U3 的输出路径 | 5A 峰 | 2.72mm | **1.36mm** | — | 铺铜，长度 ≤10mm |
| 8A 堵转工况 | 8A | — | 2.60mm | — | 靠铺铜和 slug 铜，不得仅靠单线 |
| `+3.3V` / `+3.3V_LDO` | ≤70mA | 0.30mm | — | — | 0.5mm 足够（此处噪声比压降重要） |
| `VCC_SENS` / `VCC_CEP_EXT` | ≤0.5A | 0.30mm | — | — | ≥0.5mm（F2 是 0.5A 保持） |

大电流路径一律**以铺铜为主**（等效宽度 ≥4mm、双面、过孔缝合），上表只是"最小单线"。信号网那两行的 0.30mm 是**工艺下限**（IPC 公式在 ≤0.5A 时算出来只有 0.007–0.11mm，低于任何板厂的稳定工艺），不是热要求。

过孔载流：0.3mm 孔 / 0.6mm 盘按 **≈0.5A/个** 保守算 → 3A 路径至少 6 个。散热阵列另算（§5、§10）。

温升自检（IPC-2221 外层）：`I = 0.048 · ΔT^0.44 · A^0.725`（A 单位 mil²）。例：2oz 铺铜等效 80mil 宽 → A=224mil² → 5A 时 ΔT≈4.9°C。

`C13/C17`（470µF/35V）承受 H 桥 20kHz 纹波电流，选低 ESR 件，两只并联尽量靠近 U3 的 VCC/GND 焊盘（≤10mm），走线 ≥1.5mm 或铺铜；体积大时可放板边，不得遮挡测试点与 U4/U5 上方。

## 5. H 桥的三个散热焊盘

落点（和原理图、ST 手册表 4 一致）：

| 焊盘 | 网络 | 铜皮包含谁 |
|---|---|---|
| `U3.39`（Slug1 = VCC） | `VM_12V` | `U3.13,24` + C13/C14/C15/C17/`C35` 的 VM 端 |
| `U3.37`（Slug2 = OUTA） | `MOT_A_BR` | `U3.2,8–14` + `U4.1–4`(IP+) |
| `U3.38`（Slug3 = OUTB） | `MOT_B` | `U3.23,25–29,35` + → `J2.2` / `D3.2` / `C16.2` |

- 每块铜 ≥25mm²（Top），Bottom 再镜像一块 ≥25mm²，用过孔阵列连起来；U3 三块加起来双面 ≥8cm²。
- 三块之间间距 ≥0.5mm，推荐 1.0mm；阻焊开窗不要跨岛连成一片。
- 散热过孔按 ST 给的规格做：**1.2mm×1.2mm 栅格、孔径 0.3mm±0.08、过孔到其它网络间隙 0.2mm**，每岛 ≥12 个，`VM_12V` 岛 ≥20 个（它还要带走 Buck 输出电流）。
- `VM_12V` 可以在 L3 单独铺一块（不得越出功率半区）；`OUTA/OUTB` 是开关节点，**不得**在内层大面积铺，L1+L4 局部铜加过孔即可。
- 三块铜周围 ≥5mm 内不放温度敏感件（U4 / U5 / R45–R48 / C25 / C31 / C39 / C40），也不让细信号线穿过。
- 如果整机环境 >60℃，可以加铝散热片——但三块铜是一个整金属片下面的三个不同网络，**必须用绝缘导热垫**，否则等于把三个网络短在一起。

## 6. 采样走线（精度关键路径）

### 6.1 U4 的 IP+ / IP− 取点

电流路径是 `U3.OUTA → U4.IP+(1–4) → 内部引线框架 → U4.IP−(5–8) → MOT_A → J2.1`，器件本身就是"分流器"。所以：

1. **不得用铜把 IP+（1–4）和 IP−（5–8）连起来**——外并联铜会让电流绕过内部传感路径，采样值接近 0。画完用万用表量 `U4.1↔U4.5`，必须开路（>1MΩ）。
2. IP+ 铜从 `U3` 的 OUTA/Slug2 铜岛直接连到 IP+ 焊盘群，不从铜岛远角绕细线过来；IP− 铜从焊盘群直接连到 `MOT_A` 铜岛，再由该岛去 `J2.1` / `D3.1` / `R8.1` / `R32.1`。
3. 真正要当 Kelvin 处理的是 `MOT_V_SENSE`（`R32.1`）：取点放在 `J2.1` 焊盘处或 `U4.5–8` 焊盘群上，用细线从铜岛边缘引出（不要在 3A 铜的中段取），全程和 AGND 成对走，不穿功率铜。否则铜阻上的 `I×R` 会叠进测量。

### 6.3 VREF

`R10`(10Ω) 从 `+3.3V` 拉出，`C25`(1µF)+`C31`(100nF) 到 AGND，三者距 `U5.VREF`(13) ≤3mm（C25 宜 ≤2mm）。R10 的 `+3.3V` 端从 C29/C30 之后的静轨铜取，不从 LDO 侧或 CAN 侧引。VREF 走线宽 0.4mm、尽量短，旁边不得走 SPI 时钟；C25/C31 的地脚各自独立打过孔到 AGND。

### 6.4 模拟线与功率线的间距

模拟小信号（`VIOUT`/`I_SENSE`/`CS_ADC`/`VM_SENSE`/`MOT_V_SENSE`/`VREF`）离 `SW`/`MOT_A`/`MOT_B`/`OUTA`/`OUTB`/`VM_12V` 开关铜 **≥10mm**；离普通数字线（SPI/PWM/INA/INB）**≥3mm**。

原因：12bit + 3.3V 参考 → 1LSB = 0.806mV，而 ACS725 是 66mV/A → 1LSB ≈ 12.2mA。开关节点 20V / 10ns 的边沿通过几十 fF 的寄生电容即可注入 mA 级电流，在 1kΩ 源阻抗上形成 mV 级误差。间距从 2mm 增至 10mm（耦合约按 1/d 降）约降 5 倍，中间再加地可再降一个量级，即可压到 1LSB 以下。

## 7. ACS725 的隔离与间距

`U4 = ACS725LMA`（SOIC-16W，本体 10.3×7.5mm，脚距 1.27mm；量程 ±20A、灵敏度 66mV/A、3.3V 供电）。手册给的隔离指标：**Clearance（空气路径）7.5mm、Creepage（沿本体表面）8.2mm**、DTI 90µm、V_ISO 4800V_RMS、CTI 400–599V。

7.5mm 正好等于封装本体宽度——也就是说，空气路径就是"跨过本体"。**只要有任何一层铜从 IP 侧（左列 1–8）铺到信号侧（右列 9–16），这条路径就被短路了，隔离指标直接作废。**

具体做法：

1. 以 U4 本体投影（10.3×7.5mm，含焊盘之间的区域）画一个 Keepout/Cutout，**所有层**都禁布铜（除 U4 自己的焊盘）。
2. 左列铜：`MOT_A_BR` 和 `MOT_A` 两块铜只延伸到各自焊盘外缘（外扩 ≤0.3mm 做工艺补偿），不得向内伸到本体下方；两块铜之间留 ≥0.5mm 间隙——不能靠铜把 IP+ 和 IP− 连起来。
3. 右列铜：`AGND`（15/11/14）、`+3.3V`（10）、`FLT`（13）、`ISENSE_RAW`（12）都从右侧引出，与左列铜距离由本体宽度保证，不得用铺铜就近连通。
4. **不需要铣槽**：本板 IP 侧最高 20V，而 7.5/8.2mm 是给 1000V 级工作电压设计的，余量两个数量级。不铺铜即可。
5. 丝印：在 U4 两侧各画一条虚线"隔离带"并标 `ISO BARRIER`，方便目检有没有误铺铜。
6. U4 没有散热焊盘，热量靠 IP 引线走，所以左列两块铜要给足面积（各 ≥100mm² 并加过孔）。

其它间距：`VBUS_20V`(20V) 与相邻网 ≥0.5mm；`VM_12V`（泵升到 ~20.7V）与相邻网 ≥0.5mm，与逻辑/模拟铜 ≥2mm；≤30V 的不同网最小铜间距 ≥0.2mm（推荐 0.3mm，瓶颈是板厂工艺和焊接桥连，不是击穿）。

## 9. 热设计

先给式子，后面直接代：

```
Tj = Ta + Rθja × Pd
Pd(U3) = I² × (R_ON_HS + R_ON_LS)                    导通为主，开关损耗在这个频率可忽略
Pd(U2) = Iout² × R_DS(on) × D + 开关损耗 + 栅驱动     非同步 Buck，低边损耗算在 D2 头上
Pd(U11) = (5 − 3.3) × Iout                     LDO（线性，输入已被 U10 钳到 5V）
Pd(U10) = Pout × (1/η − 1)                     DC-DC（开关型，η≈0.8–0.9，耗散≈0.1–0.2W）
Pd(D2) = Vf × Iout × (1−D)                            续流二极管
Pd(L1) = Iout² × DCR
Pd(R8) = f_sw × C16 × V²                              缓冲电阻
```

### 9.1 U3（VNH5050A）—— 板上最大热源

手册参数：`R_ON_HS` = 17mΩ@−40°C / 26mΩ@25°C / 52mΩ@150°C，全温最大 60mΩ；`R_ON_LS` = 20mΩ@25°C，最大 40mΩ；导通态静态电流 36mA（无 PWM）/ 8mA（20kHz）；每腿 `R_thj-case` = 3.9°C/W；过热关断 150–200°C（typ 175°C），复位 135°C。

ST 的测试板条件是：1.6mm FR4、2oz 双面铜、散热过孔 1.2mm 栅格 / 0.3mm 孔 / 0.2mm 间隙、footprint 4.1×6.5mm，`R_thj-amb` 曲线分"双层 footprint / 2cm² / 8cm²"和"四层 16/32cm²、内层全覆盖"几档。

估算（3A 连续，Tj 自洽取 100°C 时的 R_ON：HS ≈40mΩ、LS ≈28mΩ）：
`Pd ≈ 9 × 0.068 ≈ 0.61W`；取 `Rθja ≈ 35–45°C/W`（双层、双面铜 ≥8cm²、含 slug 过孔阵列）→ ΔT ≈ 21–27°C → **Tj ≈ 46–52°C @25°C**，没问题。

5A 峰值 / 堵转工况：`Pd ≈ 1.7W` → ΔT ≈ 60–77°C → Tj ≈ 85–102°C，仍在 150°C 关断阈以下，但**必须给足铜**；环境 60°C 时 Tj 会到 120–137°C，所以三块 slug 铜要双面 ≥8cm²，且三块都要焊接——仅焊一块，热阻会明显变差。

### 9.2 U2（TPS54560）

手册：`θJA = 42.0°C/W`（standard board）、`θJC(bot) = 3.6`、`θJB = 23.4`；高边 MOSFET `R_DS(on) ≈ 92mΩ`。它是**非同步** Buck，低边靠外接 D2，所以低边损耗算在 D2 里，不重复计。

12V/3A、20V 输入（D≈0.6）：高边导通 ≈ 9×0.092×0.6 = 0.50W；开关损耗（20V、3A、~20ns、400kHz）≈0.24W；栅驱动+静态 ≈0.1W → **Pd ≈ 0.85W** → ΔT ≈ 36°C → Tj ≈ 61°C@25°C、≈96°C@60°C，离 125°C 上限还有余量。5A 短时约 1.8W → Tj ≈ 101°C@25°C。

做法：EP(9) 焊到铜，IC 正下方直接打 ≥9 个 0.3mm 过孔到内层地；顶层地面积要给够。

### 9.3 D2 / L1 / R8

| 器件 | 损耗 | 做法 |
|---|---|---|
| `D2` B560C | `Vf×I×(1−D) ≈ 0.5×3×0.4 ≈ 0.6W` | SMC 本体 + 铺铜 ≥50mm²，温升目标 ≤40°C |
| `L1` SPM10065VT-150M-D | `I²×DCR`，DCR <50mΩ → 3A 时 ≤0.45W | 电感下方铺铜 + 过孔；Isat 11.7A，比 3A 工况和 6.3A 限流都宽裕得多 |
| `R8` 100Ω | `f×C×V² = 20k×10nF×12² ≈ 29mW` | 0603 都够（100mW），现用 1206 更宽松 |

### 9.4 U10（K7805 DC-DC）+ U11（LDL1117 LDO）

- `U11`：`Pd = (5 − 3.3) × Iout`。3.3V 侧负载典型 20–35mA、最坏 ≤70mA → **0.06–0.12W**，SOT-223 不特意铺铜也够。输出电容 C43+C27 共 44µF，LDL1117 对 10–100µF 陶瓷负载电容稳定。
- `U10`：开关型，12V→5V 效率约 80–90% → 自身耗散 ≈0.1–0.2W，**无需热设计**；但它是**开关噪声源** → 输入/输出电容回路面积要小，模块与 U4/U5 拉开 ≥10mm。
- `+3.3V` 静轨的噪声隔离靠 `FB1`。

### 9.5 U4 和其它

ACS725 的手册热阻 `RθJA = 23°C/W`、`RθJL = 5°C/W`（测试条件：1500mm² 2oz 铜、双面、1–4 与 5–8 脚都接铜并打热过孔）。器件自身只耗 `3.3V×10mA ≈ 33mW`，真正的热源是 IP 侧 3A 在内部引线框架和铜上的 I²R，所以 IP+/IP− 两块铜各给 ≥100mm² 并加过孔（同时这也是 §7 隔离的前提：铜只能在自己那侧）。

ACS725 的零点和灵敏度有温漂，这就是"U3（及 U10 的开关回路铜）离 U4 ≥5–10mm、不让 U4 待在功率岛散热路径上"的原因（U11 现在只耗 0.06–0.12W，不再是大热源）。

## 11. 测试点

原理图里**没有 `TP*` 器件**，所以测试点在 PCB 阶段就是裸焊盘/过孔（不进 BOM），但必须实际绘制，否则答辩时"量化测试"缺少外部交叉验证点。

必做：

| 编号 | 网络 | 放哪 |
|---|---|---|
| `TP1` | `MOT_A` | `J2.1` 旁（板边） |
| `TP2` | `MOT_B` | `J2.2` 旁 |

### 15.2 首次上电（限流，逐步进行）

| 步 | 操作 | 期望 | 异常处理 |
|---|---|---|---|
| 1 | 可调电源 + USB-C 诱骗器（或 PD 电源串功率计），**限流 0.2A** 上电 | 电流 <20mA（协商期瞬时稍高） | 撞限流 → 立刻断电，回 15.1 #7/#10 |
| 2 | 量 `VBUS_20V` | 20V ±0.5V | ≈5V → PD 没协商上，查 U1 的 CC1/CC2 和 VSET 悬空 |
| 3 | 量 `VM_12V` | 12.0V ±0.2V | 0V → 查 `U2.EN`（UVLO 17.3V）和 FB 分压；>13V → 查 FB |
| 4 | 先量 `+5V_DCDC`（U10 输出 / U11 输入），再量 `+3.3V_LDO`（C27 处） | 5.0V ±0.25V；3.30V ±0.1V（U11 固定输出） | 5V=0 → 查 U10 输入（应为 12V）；5V 正常而 3.3V 异常 → 查 U11 焊接/负载 |
| 5 | 量 `+3.3V`（C29/C30 处，FB1 之后） | 3.28–3.30V（磁珠压降是 mV 级） | 明显低 → FB1 或后级短路（也看 #15/#16） |
| 6 | 空载总电流 | <100mA（LDO 侧 20–35mA + Buck 静态） | >300mA → 立刻断电，重点查三 slug 区、U3/U2、C13 极性 |
| 7 | 测温升（或红外） | U2 / U3 温升 ≤20°C（室温 25°C 时 <50°C）；`U10`/`U11` 应基本不热 | U11 温度过高 → 查后级短路；U3 温度过高 → 查 slug 焊盘/短路 |
| 8 | 示波器量 `+3.3V` 纹波（AC 耦合、20MHz 带宽限制、弹簧地就近） | <20mVpp | 大 → 查 C29/C30 位置、FB1、探针地线太长 |

| 10 | 量 `VREF_3V3`（TP5） | 3.28–3.30V（R10 压降 <10mV） | 低 → 查 R10/C25/C31 |
| 11 | 断电 → 插上 J3（不得带电插拔）→ 先给底板上电 → 再给本板 PD 上电 | `J3.1` = 3.26–3.30V；`VCC_SENS` = 2.9–3.0V | `J3.1`=0V → 底板没上电或 L13 故障；`VCC_SENS` 等于 3.3V 或 0V → 查 F2/D10 |
| 12 | 示波器量 `CAN_TX`（U7.1）空闲态 | ≈3.3V（隐性，靠 R35 上拉） | 0V → 查上拉 |
| 13 | 接 CAN 总线（另一端有 120Ω 终端），测 `CAN_H/L` 差分 | 空闲差分 ≈0V，发帧有正确摆幅 | 无波形 → 查 R37 和终端数量（§14 第 1 条） |
| 14 | 传感器口：插一个 3.3V I²C 模块（按丝印 `1=VCC 2=GND 3=SCL 4=SDA`），扫总线 | 能读到地址；SDA/SCL 高电平 ≈2.9–3.0V | 读不到 → 先核对 J6 针序和上拉 |
| 15 | 电机空载：先 5% 占空比 / 20kHz，再逐步加上去 | `MOT_A/B` 波形正常；`I_SENSE` 有响应；U3 温升 ≤40°C（红外） | 电流异常大/发热 → 立刻停，回 15.1 #1/#20 |
| 16 | 记录标定值 | `I_SENSE` 零点；灵敏度 66mV/A（可用 `CS_MOTOR`/R16 交叉验证）；`VM_SENSE`/`MOT_V_SENSE` 系数 15/115 = 0.1304 | 写进测试报告（选题四要的量化指标） |

顺序原则：断电插拔 → 先底板后本板上电，下电反过来。**任何时候都不得带电插拔 J3**（跨板信号只靠底板 33Ω + 本板 100Ω 限流）。
