# Motor/ —— 电机板 `MLK-F3P-Motor`（已归档）

本目录收录已归档的**电机板**（755 有刷电机、VNH5050A H 桥、TPS54560 Buck、ACS725 霍尔、MCP3204 ADC、CAN 等）。该板**不再维护**。

归档原因：该板电路复杂（PD 取电、Buck、H 桥、霍尔、ADC、CAN、板载过流保护与传感器口）；采用市售整套电机（电源适配器 + 调速器 + 755 电机）+ 传感器载板即可覆盖本选题的采集需求，无须自绘电机板。

- 工程文件：实际使用 `~/Documents/LCEDA-Pro/projects/MLK-F3P-Motor.eprj2`；仓库归档副本 `eda/archive/MLK-F3P-Motor.eprj2`。
- `MLK-F3P-DR1M90G`（故障诊断系统）为独立工程，其外设（传感器载板）见 [`../传感器板-说明.md`](../传感器板-说明.md)。
