# 时域与频域特征

本规格定义 PL 时域特征、独立 FFT 的数值格式、握手、资源规划和验证方法。寄存器唯一来源为 [`PL-PS接口约定.md`](../../../docs/PL-PS接口约定.md) §4.3。

## 1. 方案与通道

| 项 | 方案 | 依据 |
|---|---|---|
| 时域通道 | 振动 X/Y/Z、电流各一个 `time_features` | 三轴保留方向信息；电流保留 DC 与趋势 |
| 窗口 | 默认 N=256，步长 H=128；支持 N=512，1≤H≤N | ADXL345 3200 SPS 时窗口为 80/160 ms，128 点步长为 40 ms |
| 电流窗口 | 与振动相同的样本数、独立 valid | 860 SPS 下 256 点约 297.7 ms，128 点约 148.8 ms；读取无 ALERT/RDY 判新样本保证 |
| 滑窗 | 环形 RAM，按接受样本计数；首 N 点产生第一窗，此后每 H 点产生一窗 | 保留重叠样本，不补零、不包含复位前样本 |
| 中心矩 | d=Nx−Σx，精确整数累加 d²/d⁴ | 避免 DC 舍入对方差和峭度的偏差 |
| 开方 / 除法 | 逐对开方；160 bit 恢复除法，16 bit 分段减法 | 有界运算宽度，限制单拍进位链长度 |
| 频域 | 自研串行 radix-2 DIT，256/512 点 | 无厂商 PL FFT IP；3.2 kSPS 吞吐允许复用蝶形与缓存 |
| FFT 窗函数 | 编译期矩形或周期 Hann | 矩形用于定点基准；Hann 抑制泄漏 |
| CAN | 待定 | 不在当前实现范围 |

所有新增 RTL 使用 `I_clk` 时钟与低有效同步复位，不生成内部时钟。AXI 本体与采样/特征输入要求处于同一时钟域；SoC 时钟与 CDC 为 TBD。

## 2. 时域接口

实现：[`time_features.v`](../01_rtl/features/time_features.v)、[`sensor_features.v`](../01_rtl/features/sensor_features.v)。参数范围为 `WINDOW_LOG2=8/9`、`HOP=1..N`。

| 信号 | 方向 | 规格 |
|---|---|---|
| `I_sample` | 输入 | signed16 原始码 |
| `I_valid / O_ready` | 输入 / 输出 | 时钟上升沿两者均为 1 时接受样本；普通接受需两拍，计算期间 ready=0 |
| `O_overrun` | 输出 | valid=1 且 ready=0 的每个周期置 1，该周期输入不进入窗口 |
| `O_features` | 输出 | 七个 64 bit 字段，共 448 bit；低位起顺序见 §3 |
| `O_valid` | 输出 | 单拍结果有效；结果保持至下一次结果发布或复位 |
| `O_flags` | 输出 | bit0=零 RMS，bit1=零方差 |

传感器接口无法反压，顶层直接连接采样 valid 并提供 `S_feature_overrun`。无丢样条件：采样间隔大于特征计算最长阻塞时间。256/512 点最长阻塞分别为 7084/8364 拍，在 100 MHz 下为 70.84/83.64 µs，低于 3200 SPS 的 312.5 µs 样本间隔。

共同时基 / 对齐帧独立于特征窗口：`timebase` 在原始 valid 接收拍记录 `r_ts`，1 kHz 锁存最新值；特征仍按 valid / ready 接受原始样本，不按帧重采样。FRAME_TS 是帧毫秒数，不能作为窗口结束时刻；特征窗口时间戳为 TBD。`feature_bank` 快照 / SEQUENCE 语义保持，见接口契约 §4.3。

未接 AXI/DMA 时结果只能由仿真或后续读出接口观察；`_unused` 常量归约不能防止综合优化。

环形 RAM 在接受拍读取旧样本、下一拍写入新样本，读写不在同拍，避免 ERAM 同地址冲突。复位清计数、滚动和、输出与状态；RAM 不复位，重新填满 N 点后才使用完整窗口。每次扫描从环形写指针开始，按时间顺序处理，过零仅统计窗口内部 N−1 个相邻对。

## 3. 特征与定点格式

令 S=Σx，E₂=Σx²，D₂=Σ(Nx−S)²，D₄=Σ(Nx−S)⁴，P=max(abs(x))，Z 为符号跨越计数。符号分类：负数为 1，零和正数为 0；例如 −1→0 与 0→−1 各计一次，0→1 不计。

| 字段序号 | 特征 | 输出整数的定义 | 单位 |
|---|---|---|---|
| 0 | 均值 / DC | S×2¹⁶/N，精确 | 原始码，signed Q16 |
| 1 | RMS | floor(sqrt(E₂×2³²/N)) | 原始码，unsigned Q16 |
| 2 | 总体方差 | floor(D₂×2¹⁶/N³) | 原始码²，unsigned Q16 |
| 3 | 峰峰值 | max(x)−min(x) | 原始码，unsigned 整数 |
| 4 | 峰值因子 | floor(P×2³²/RMS_Q16) | 无量纲，unsigned Q16 |
| 5 | 过零率 | floor(Z×2¹⁶/(N−1)) | 无量纲，unsigned Q16 |
| 6 | 峭度 | floor(D₄×N×2¹⁶/D₂²) | Pearson 峭度，不减 3，unsigned Q16 |

RMS=0 时峰值因子为 0，D₂=0 时峭度为 0；FLAGS 区分退化窗口与普通数值。峰值因子使用已量化的 RMS_Q16 作除数。DC/RMS 包含直流分量；用于振动交流频域时去 DC 的接入策略为 TBD。电流结果为 ADC 原始码特征，霍尔偏置和标定不在本块内部执行，不直接等同于安培单位的有效值。

| 中间量 | 位宽 | 上界说明（N≤512） |
|---|---|---|
| S / E₂ | signed32 / unsigned48 | abs(S)≤N×32768；E₂≤N×32768² |
| d / d² | signed32 / unsigned64 | abs(d)<2²⁵；d²<2⁵⁰ |
| d⁴ / D₄ | unsigned128 | D₄<N×2¹⁰⁰≤2¹⁰⁹ |
| D₂ / D₂² | unsigned64 / unsigned128 | D₂<2⁵⁹；D₂²<2¹¹⁸ |
| 峭度分子 | unsigned160 | D₄×N×2¹⁶<2¹³⁴ |
| 特征字段 | 64 bit | 全 signed16 输入范围不饱和；最终除法/开方按表取整 |

## 4. FFT 接口与缩放

实现：[`fft_radix2.v`](../01_rtl/fft/fft_radix2.v)、[`fft_coeff_rom.v`](../01_rtl/fft/fft_coeff_rom.v)。参数 `LOGN=8/9`，`WINDOW=0/1`。FFT 为独立块，尚未并入 `fpga_top`、寄存器或 DMA。

| 项 | 规格 |
|---|---|
| 输入 | signed16 实数，自然顺序；I_valid 与 O_ready 同拍接受 |
| 输入背压 | 每次锁存后等待一拍写 RAM；收满 N 点后阻塞至全部结果输出 |
| 窗函数 | 矩形 w=1；周期 Hann w[n]=(1−cos(2πn/N))/2，分母为 N |
| 系数 | round(w×32768)，旋转因子 round(exp(−j2πk/512)×32768)；+1 精确编码为 32768 |
| 内部格式 | signed32 Q8；实输入乘窗后右移 7 位进入缓存 |
| 缩放 | 每级蝶形除以 2，负数右移向负无穷取整；整体输出 DFT(x×w)/N |
| 输出 | 自然顺序 bin=0..N−1，复数 signed32 Q8；正向 FFT、负指数 |
| 输出握手 | O_valid 与 I_ready 同拍接受；背压期间 O_valid、bin、real、imag、last 保持 |
| `O_last` | 最后一个 bin 的有效电平，握手时表示帧尾 |
| 帧并行 | 单缓存、单帧；无输入/计算/输出帧间重叠 |
| 计算延迟 | 测试背压下，最后一个输入接受至首 bin 接受最大为 8198/18440 拍（256/512）；输出背压可无限延长整帧完成时间 |
| 频率刻度 | f[k]=k×Fs/N；Fs=3200 Hz 时 256/512 点分辨率为 12.5/6.25 Hz |

FFT 缓存使用同步单读/单写口，A/B 分拍访问，输入写入位反转地址；每个蝶形包含读取、复乘流水、缩放、写回。旋转母表为 512 点，256 点索引等效取偶数旋转地址。系数 ROM 由 [`gen_dsp_vectors.py`](../02_sim/gen_dsp_vectors.py) 确定性生成，RTL 运行时不使用 real/$sin/$cos。

## 5. 资源与构建

器件 ERAM 上限 280×20K，DSP 上限 240。时域每通道缓存 N×16 bit，FFT 每实例缓存 N×64 bit；旋转 ROM 为 256×36 bit、窗 ROM 为 512×17 bit。实际 ERAM 颗粒取决于 TD 推断与宽深映射，以 `route.area` 为准。

`fpga_top` 例化四路时域与本地快照，保持现有引脚和 LED 语义。未接 AXI/DMA，结果逻辑可能被优化，生产工程资源不能用来核验新增算法成本。

[`validation_top.v`](validation_top.v) 为独立综合壳，例化四路时域、256/512 点 Hann FFT 与完整 AXI/中断/快照本体，以变化地址读出和签名寄存器保持数据通路可观察。该壳仅输出时钟/LED 端口，用单独生成的约束与工程验证，不用于下载。

在仓库根进入 `nix develop .#fpga`，再于 `fpga/` 执行：

```bash
./uisrc/02_sim/run_sim.sh
```

独立 headless 构建命令同 [`README.md`](README.md) §1，将脚本替换为 `build_validation.tcl`。输出位于 `uisrc/out/validation/`。该脚本只清理自身生成的 `validation_Runs/`，每次全新 `open_project`。

## 6. 验证

| 测试平台 | 覆盖 |
|---|---|
| `tb_time_features`，256/512 | 重叠滑窗、零值、正负 DC、满幅常量/交替、冲激、斜坡、随机、复位丢弃半窗、拒收/overrun、最长阻塞周期 |
| `tb_fft`，256/512 × 矩形/Hann | 零值、DC、冲激、余弦、带 DC 正弦、Nyquist、满幅随机、输入空隙、输出背压、自然 bin 顺序与 last |
| `tb_axi_lite_reg` | AW/W 顺序、WSTRB、B/R 背压、非法地址/RO 写、原始数据、阈值、W1C、单拍 IRQ、屏蔽保留、同拍清除/事件、快照原子性、软复位、AXI 半事务复位 |
| `tb_timebase` | 100 MHz 计数、1 kHz 栅格、三路时间戳、同拍 valid 帧锁存、保持 / 使能 / 复位与回绕 |
| `tb_fpga_top` | 实际集成顶层中注入采集结果，核对三路时间戳 / 帧、特征、本地快照和 LED 语义 |

参考向量为 Python 大整数计算；FFT 逐级整数模型同时与独立直接 DFT 核对，当前四配置误差最大 0.102 个输入 LSB。固定向量在 [`vectors/`](../02_sim/vectors/) 纳入版本控制，仿真不依赖 Python。重新生成：

```bash
python3 uisrc/02_sim/gen_dsp_vectors.py
```

RTL lint：`verilator --lint-only -Wall -Wno-UNUSEDSIGNAL -Wno-PINCONNECTEMPTY --top-module validation_top uisrc/06_doc/validation_top.v uisrc/01_rtl/axi_lite_reg.v uisrc/01_rtl/timebase.v uisrc/01_rtl/p2f_irq.v uisrc/01_rtl/features/*.v uisrc/01_rtl/fft/*.v`。仅豁免未使用的高位/空接状态端口；位宽、锁存、多驱动等诊断仍为错误。
